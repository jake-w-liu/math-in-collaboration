\section{Week 8}
\sol{8.1}{\emph{The matchings.} The empty set is a matching, and so is each of the three single edges Ada--$1$, Ada--$2$ and Ben--$1$. Of the three sets with two edges, $\{\text{Ada--}1,\ \text{Ada--}2\}$ is not a matching, because both edges have the endpoint Ada, and $\{\text{Ada--}1,\ \text{Ben--}1\}$ is not, because both have the endpoint~$1$; the remaining one, $\{\text{Ada--}2,\ \text{Ben--}1\}$, is a matching. The set of all three edges contains Ada--$1$ and Ada--$2$, so it is not a matching. Hence the graph has exactly five matchings.

\emph{Which are maximal.} Any edge can be added to the empty matching, Ben--$1$ to $\{\text{Ada--}2\}$, and Ada--$2$ to $\{\text{Ben--}1\}$, so these three are not maximal. The matching $\{\text{Ada--}1\}$ is maximal, because Ada--$2$ shares the endpoint Ada with it and Ben--$1$ shares the endpoint~$1$. So is $\{\text{Ada--}2,\ \text{Ben--}1\}$, because adding the only remaining edge, Ada--$1$, would give Ada two tasks.

\emph{Which are maximum.} The largest number of edges is two, so $\{\text{Ada--}2,\ \text{Ben--}1\}$ is the only maximum matching. Hence $\{\text{Ada--}1\}$ is the only matching that is maximal but not maximum.}
\sol{8.2}{In the matching $\{a\text{--}2,\ b\text{--}1\}$, the student $c$ is unmatched, tasks $1$ and $2$ are used, and task~$3$ is unused. Search from $c$.
\begin{itemize}
\item Inspect $c$. Its only edge, $c$--$2$, is unmatched, so task~$2$ is reached with predecessor $c$. Task~$2$ is held by $a$, so $a$ is reached with predecessor~$2$.
\item Inspect $a$. The edge $a$--$2$ is matched; the edge $a$--$1$ is unmatched, so task~$1$ is reached with predecessor $a$. Task~$1$ is held by $b$, so $b$ is reached with predecessor~$1$.
\item Inspect $b$. The edge $b$--$1$ is matched; the edge $b$--$3$ is unmatched, so task~$3$ is reached with predecessor $b$. Task~$3$ is unused, and the search succeeds.
\end{itemize}
Following the predecessors back from task~$3$ gives the augmenting path
\[
c\;\text{--}\;2\;\text{--}\;a\;\text{--}\;1\;\text{--}\;b\;\text{--}\;3.
\]
Flipping removes its matched edges $a$--$2$ and $b$--$1$ and adds its unmatched edges $c$--$2$, $a$--$1$, $b$--$3$, which gives the matching
\[
\{a\text{--}1,\ b\text{--}3,\ c\text{--}2\}.
\]
Each student now has an acceptable task, and the three tasks are different.}
\sol{8.3}{Let $S$ be the set of all three students. Then $N(S)=\{1,2\}$, so $|N(S)|=2<3=|S|$, and $S$ is a shortage set. It certifies that no full assignment exists, since a full assignment would give the three students three different tasks from $N(S)$, which has only two members.

Each student has two options, but adding them up, $2+2+2=6$, counts the same two tasks again and again; what matters is the number of \emph{different} tasks available to the group, which is $2$. No smaller group is a shortage set: the empty group accepts $0$ tasks, which is not fewer than its $0$ members; one student accepts $2\ge1$ tasks; and any two students together accept $2\ge2$ tasks.}
\sol{8.4}{(a)~The proof uses twice that the vertices of the path are all different: to conclude that an inner vertex lies on exactly two path edges, one matched and one unmatched, and an end on exactly one, so that after the flip each lies on exactly one edge of the new matching; and to count the path's edges as $r+1$ unmatched and $r$ matched ones, all different. A vertex appearing twice could lie on two unmatched edges of the walk, both added by the flip, and would then have two partners.

For an example, take students $x$, $s$, $u$ and tasks $1$, $2$, $3$, with edges $x$--$1$, $s$--$1$, $s$--$2$, $s$--$3$, $u$--$1$, $u$--$2$, and the matching $M=\{s\text{--}1,\ u\text{--}2\}$. Student $x$ is unmatched and task~$3$ is unused. The walk
\[
x,\ 1,\ s,\ 2,\ u,\ 1,\ s,\ 3
\]
uses the edges $x$--$1$, $s$--$1$, $s$--$2$, $u$--$2$, $u$--$1$, $s$--$1$, $s$--$3$, which are unmatched, matched, unmatched, matched, unmatched, matched, unmatched in turn. So it is an alternating walk from an unmatched student to an unused task, but it visits task~$1$ and student $s$ twice. Flipping along it removes $s$--$1$ and $u$--$2$ and adds $x$--$1$, $s$--$2$, $u$--$1$, $s$--$3$. The result
\[
\{x\text{--}1,\ s\text{--}2,\ u\text{--}1,\ s\text{--}3\}
\]
is not a matching: task~$1$ lies on two of its edges, and so does student~$s$. Cutting out the part of the walk between the two visits to task~$1$ leaves $x,1,s,3$, which is an augmenting path; flipping along it gives the matching $\{x\text{--}1,\ s\text{--}3,\ u\text{--}2\}$.

(b)~The lengths of the alternating walks from an unmatched student to an unused task form a nonempty set of natural numbers, so by the well-ordering property there is a shortest such walk, say $v_0,v_1,\ldots,v_k$, with $x=v_0$. Since $x$ is a student and $v_k$ is a task, $k\ge1$. The graph is bipartite, so $v_i$ is a student when $i$ is even and a task when $i$ is odd. The first edge is unmatched, because $x$ is unmatched, and the edges alternate, so the $m$th edge is unmatched when $m$ is odd and matched when $m$ is even.

Suppose, for contradiction, that $v_i=v_j$ for some $i<j$. Then $i$ and $j$ have the same parity, because $v_i$ and $v_j$ lie on the same side, so $j-i$ is even. Cut out the entries $v_{i+1},\ldots,v_j$, as in the proof of Lemma~\ref{ch07:lem:shortest-walk}. What remains, $v_0,\ldots,v_i,v_{j+1},\ldots,v_k$, is a walk from $x$ to the same unused task, for the reason given in that proof. Its first $i$ edges are unchanged. If $j<k$, each later edge is an edge of the old walk whose position number has dropped by $j-i$: for example, the new $(i+1)$st edge $v_iv_{j+1}$ is the old $(j+1)$st edge $v_jv_{j+1}$. Since $j-i$ is even, each of these edges keeps the parity of its position, so it is still unmatched exactly when its position is odd, and the shorter walk is still alternating. Its length $k-(j-i)<k$ contradicts the choice of a shortest walk. Hence a shortest walk repeats no vertex: it is an alternating path with at least one step whose ends are both unmatched, that is, an augmenting path.}
\sol{8.5}{A quantity that increases by one at every step can still do so forever, like the counter $0,1,2,3,\ldots$. To conclude that a procedure stops, we also need a ceiling that the quantity can never pass.

Finiteness of $L$ provides this ceiling: as shown at the end of Section~\ref{ch08:sec:augment}, sending each edge of a matching to its student is an injective map from the matching to $L$, so a matching has at most $|L|$ edges. Starting from $k$ edges, after $m$ steps the matching has $k+m\le|L|$ edges. Hence at most $|L|-k$ steps can occur, and at most $|L|$ from the empty matching.}
\sol{8.6}{(a)~The search reaches a task only by a move from a reached student $s$ along an unmatched edge $s$--$t$, and a student other than $x$ only by a move from a reached used task to its owner.

Every task $t$ in $B$ was reached from some student $s$ in $A$ along an edge $s$--$t$, so $s$ accepts $t$, and $t\in N(A)$. Thus $B\subseteq N(A)$. Conversely, let $t\in N(A)$, and choose a student $s\in A$ that accepts $t$.
\begin{itemize}
\item \emph{The edge $s$--$t$ is unmatched.} Because the search is complete, $s$ has been inspected, and inspecting $s$ follows every unmatched edge at $s$. So $t\in B$.
\item \emph{The edge $s$--$t$ is matched.} Then $s$ is matched, so $s\ne x$, and $s$ was reached by a move from the task it holds, which is $t$. So $t\in B$.
\end{itemize}
Hence $N(A)=B$. Completeness is used only in the unmatched case.

(b)~The containment $B\subseteq N(A)$ still holds, with the same proof, and so does the matched case of $N(A)\subseteq B$, which uses only the way students are reached. Only the unmatched case can fail, because a student that has not been completely inspected may have an unmatched edge that the search never followed. So $N(A)\subseteq B$ need not hold.

For example, let Ada accept tasks $1$ and $2$, let Ben accept only task~$1$, and let $M=\{\text{Ben--}1\}$. Search from Ada, and stop right after reaching task~$1$ and its owner Ben, before following the edge Ada--$2$. Then $A=\{\text{Ada},\text{Ben}\}$ and $B=\{1\}$, but $N(A)=\{1,2\}\not\subseteq B$.

Now take any early-stopped search in which $N(A)\subseteq B$ fails. Step~1 of the proof of Proposition~\ref{ch08:prop:shortage} still works: every reached task is used, because the search has reached no unused task; its owner has been reached, because the owner of a used task is marked as reached at the moment the task is; and every reached student other than $x$ was reached from the task it holds. So $|B|=|A|-1$. Since $B\subseteq N(A)$ and $N(A)$ contains a task outside $B$, we get $|N(A)|\ge|B|+1=|A|$, so $A$ is not a shortage set. In the example, $|N(A)|=2=|A|$.}
