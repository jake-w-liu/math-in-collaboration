\sol{6.1}{The class $[-2]_5$ consists of the integers $-2+5k$ with $k$ an integer. Taking $k=-2,-1,0,1,2$ gives
\[
-12,\quad-7,\quad-2,\quad3,\quad8.
\]
These are all the members between $-12$ and $12$: the next members on either side, $-17$ and $13$, lie outside the interval. The member of the class in $\{0,1,2,3,4\}$ is $3$, since $3-(-2)=5$; equivalently, $-2=(-1)\cdot5+3$ with $0\le3<5$. So $[-2]_5=[3]_5$.}
\sol{6.2}{Suppose $[a']_m=[a]_m$ and $[b']_m=[b]_m$. By Proposition~\ref{ch06:prop:classes}(b), $a'\equiv a$ and $b'\equiv b\pmod m$, so
\[
 a'=a+mk,\qquad b'=b+m\ell
\]
for integers $k$ and $\ell$. The output classes $[a'b']_m$ and $[ab]_m$ are equal exactly when $m$ divides $a'b'-ab$. Compute:
\begin{align*}
 a'b'-ab
 &=(a+mk)(b+m\ell)-ab\\
 &=ab+am\ell+mkb+m^2k\ell-ab\\
 &=m(a\ell+bk+mk\ell).
\end{align*}
The expression in parentheses is an integer, so $m$ divides $a'b'-ab$ and $[a'b']_m=[ab]_m$, although the products $a'b'$ and $ab$ themselves can differ. Since both representatives were allowed to change at once, the argument covers every choice of names for the two classes.}
\sol{6.3}{The rotation $r_2$ sends seat $j$ to seat $(j+2)\bmod4$, so applying it twice sends
\[
0\to2\to0,\qquad1\to3\to1,\qquad2\to0\to2,\qquad3\to1\to3.
\]
Thus $r_2\circ r_2=r_0=\id$. By the definition in Section~\ref{ch03:sec:functions}, a map $h$ is an inverse of $r_2$ when $h\circ r_2=\id$ and $r_2\circ h=\id$; for $h=r_2$, both conditions say $r_2\circ r_2=\id$. So $r_2$ is its own inverse. It is not the identity, because the identity leaves every seat in place, while $r_2$ moves seat $0$ to seat $2$.}
\sol{6.4}{Yes. Write $X\sim Y$ when $\abs{X}=\abs{Y}$, and let $X$, $Y$, $Z$ be sets in the collection.
\begin{itemize}
\item \emph{Reflexivity:} $\abs{X}=\abs{X}$, so $X\sim X$.
\item \emph{Symmetry:} if $\abs{X}=\abs{Y}$, then $\abs{Y}=\abs{X}$, so $X\sim Y$ implies $Y\sim X$.
\item \emph{Transitivity:} if $\abs{X}=\abs{Y}$ and $\abs{Y}=\abs{Z}$, then $\abs{X}=\abs{Z}$, so $X\sim Y$ and $Y\sim Z$ imply $X\sim Z$.
\end{itemize}
Each property comes from the same property of equality of numbers, so $\sim$ is an equivalence relation. The class of a set $X$ consists of all sets in the collection with as many elements as $X$; for instance, $\{1,2\}$ and $\{p,q\}$, with $p\ne q$, lie in the same class if both belong to the collection.}
\sol{6.5}{The rule is well-defined when $[a]_m=[b]_m$ always implies $[a]_d=[b]_d$. We prove the two directions of ``exactly when'' separately.

First suppose $d$ divides $m$, say $m=dt$ with $t$ an integer. Let $[a]_m=[b]_m$. By Proposition~\ref{ch06:prop:classes}(b), $a-b=mk$ for an integer $k$, so $a-b=d(tk)$, and $d$ divides $a-b$. By the same proposition, $[a]_d=[b]_d$, so the rule is well-defined.

Conversely, suppose the rule is well-defined. The integers $0$ and $m$ represent the same class modulo $m$, because $m-0=m\cdot1$, so their output classes agree: $[0]_d=[m]_d$. By Proposition~\ref{ch06:prop:classes}(b) once more, $d$ divides $m-0=m$.}
\sol{6.6}{Use the family $\{\{1\},\{1,2\},\{3\}\}$, ordered by inclusion. The sets $\{1,2\}$ and $\{3\}$ are maximal, because no other member contains either of them. The set $\{1\}$ is not maximal, because $\{1\}\subseteq\{1,2\}$ and $\{1\}\ne\{1,2\}$. So there are exactly two maximal members. There is no maximum: a maximum is always maximal (Section~\ref{ch06:sec:order}), so it would have to be $\{1,2\}$ or $\{3\}$, but neither of these contains the other.

Now add the set $\{1,2,3\}$. Every member of the new family $\{\{1\},\{1,2\},\{3\},\{1,2,3\}\}$ is a subset of $\{1,2,3\}$, so $\{1,2,3\}$ is a maximum. Notice that $\{1,2\}$ and $\{3\}$ are no longer maximal, because $\{1,2,3\}$ lies strictly above each of them. Whether an element is maximal, or a maximum, depends on the family it is compared with.}
