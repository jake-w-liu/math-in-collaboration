\section{The smallest amount of Python needed}\label{appD:sec:python}
The programs in this appendix are written in Python, a free programming language that runs on all common operating systems; any version from Python~3.10 on will do. They use only Python's \emph{standard library}, the collection of tools that comes with every Python installation, so nothing else has to be installed.

\subsection*{Running a program}
A Python program is a plain text file whose name ends in \code{.py}, for example \code{signs.py}. Write it in a plain text editor; a word processor adds formatting that Python cannot read. To run the program, open a \emph{terminal}, a window for typing commands to the computer. Move to the folder that contains the file by typing \code{cd} followed by the location of that folder; for example, \code{cd Documents/math} moves into the folder \code{math} inside \code{Documents}. Then type
\par\noindent\begin{minipage}{\linewidth}
\begin{lstlisting}
python3 signs.py
\end{lstlisting}
\end{minipage}\par
On some systems the command is \code{python} instead of \code{python3}; \code{python3 -{}-version} shows which version is installed.

Short calculations can also be typed directly into Python. Type \code{python3} in the terminal with no file name, and Python shows its \emph{prompt}, usually \code{>{}>{}>}, to say that it is waiting for a line of Python (not a terminal command such as \code{python3 signs.py}); typing \code{2 + 2} and pressing Enter displays \code{4}, and \code{exit()} returns to the terminal. The characters \code{>{}>{}>} belong to the prompt, so never type them or copy them into a program file.

\subsection*{Names, numbers and lists}
The line \code{x = 5} stores the value $5$ under the name \code{x}, for later lines to use; a later line \code{x = x + 1} replaces the stored value by $6$. So the sign \code{=} in Python is an instruction to store a value, not a claim that two things are equal; read as an equation, $x=x+1$ would be false for every number. To \emph{test} whether two values are equal, Python uses \code{==}: \code{2 + 2 == 4} is \code{True}, and \code{2 + 2 == 5} is \code{False}. The other comparisons are written \code{<}, \code{<=}, \code{>}, \code{>=}, and \code{!=} for ``is not equal to.''

Arithmetic uses \code{+}, \code{-}, \code{*} for multiplication, and \code{/} for division. Two stars denote a power, so \code{2 ** 10} is $2^{10}=1024$, and \code{abs(-3)} is the absolute value $3$. The sign \code{\%} gives the remainder of Section~\ref{ch05:sec:euclid}: \code{17 \% 5} is $17\bmod 5=2$, and \code{-7 \% 5} is $3$, because $-7=(-2)\cdot5+3$ with $0\le3<5$. The command \code{print} displays values separated by spaces: \code{print(x, x + 1)} displays \code{6 7} when \code{x} holds $6$.

A \emph{list} is an ordered collection of values, written in square brackets. In \code{a = [1, 1, 1, -1]}, the first entry is \code{a[0]}, not \code{a[1]}: Python numbers positions from zero, just as Chapter~\ref{ch:signs} numbers the entries of a sign sequence. So \code{a[3]} is the last entry, $-1$, and the \emph{length} \code{len(a)}, the number of entries, is $4$. The line \code{a.append(9)} adds the entry $9$ at the end of \code{a}, and \code{a.pop()} removes the last entry of \code{a} and hands it back as its value.

\subsection*{Loops}
A \code{for} loop repeats a block of lines once for each value in a range. The block consists of the indented lines below the \code{for} line; Python uses this indentation, not brackets, to tell where the block ends. For example:
\par\noindent\begin{minipage}{\linewidth}
\begin{lstlisting}
a = [1, 1, 1, -1]
value = 0
for j in range(3):
    value = value + a[j] * a[j + 1]
print(value)
\end{lstlisting}
\end{minipage}\par
Here \code{range(3)} produces the values $0,1,2$: it starts at zero and stops just before $3$. So the indented line runs three times, with $j=0$, $1$ and $2$, adding the products $a_0a_1=1$, $a_1a_2=1$ and $a_2a_3=-1$ to the running total in \code{value}, which goes from $0$ to $1$, $2$ and back to $1$; the program prints $1$, the aperiodic correlation $A_1$ of $(1,1,1,-1)$ computed in Section~\ref{ch14:sec:aperiodic}.

With two numbers, \code{range(1, 14)} produces $1,2,\ldots,13$: it starts at the first number and stops just before the second. A loop can also run through a list: a block that begins with \code{for x in [2, 3, 5]:} is carried out with \code{x} equal to $2$, then $3$, then $5$.

\subsection*{Functions}
A \emph{function} packages a calculation so that it can be used again with different inputs.
\par\noindent\begin{minipage}{\linewidth}
\begin{lstlisting}
def correlation(a, shift):
    value = 0
    for j in range(len(a) - shift):
        value = value + a[j] * a[j + shift]
    return value
\end{lstlisting}
\end{minipage}\par
The \code{def} line names the function, \code{correlation}, and its two inputs, \code{a} and \code{shift}; the indented lines below it carry out the calculation, and \code{return} gives the result. For a list of length $n$ and a shift $s$, the loop runs over \code{range(n - s)}, so $j$ takes the values $0,1,\ldots,n-1-s$, exactly the summation range in the definition of $A_s$ (Definition~\ref{ch14:def:aperiodic}). For example, \code{correlation([1, 1, 1, -1], 3)} is $a_0a_3=-1$, the value of $A_3$ found in Section~\ref{ch14:sec:aperiodic}. The function checks neither that \code{a} is a sign sequence nor that $1\le s\le n-1$, as the definition requires: given $n$ signs and the shift $0$, it simply returns $n$.

\subsection*{Decisions and other loops}
A line \code{if} \emph{condition}\code{:} is followed by an indented block, which is carried out only when the condition is true. Conditions can be combined with the words \code{and}, \code{or} and \code{not}, which have the meanings of Section~\ref{ch02:sec:connectives}. A \code{while} loop repeats its block as long as its condition is true. After the following lines, for example, \code{n} holds $8$, the smallest natural number whose square is at least $50$:
\par\noindent\begin{minipage}{\linewidth}
\begin{lstlisting}
n = 0
while n * n < 50:
    n = n + 1
\end{lstlisting}
\end{minipage}\par
Inside a loop, \code{break} leaves the innermost loop containing it at once, and \code{continue} skips the rest of the block and goes on with the next pass. The special value \code{None} means ``no value here''; the test \code{x is None} asks whether \code{x} holds this value, and \code{x is not None} asks the opposite.

\subsection*{Tuples, sets and dictionaries}
A \emph{tuple} is like a list, with entries numbered from zero, but is written with round brackets, as in \code{(1, -1, 1)}, and cannot be changed once made. A tuple is a natural way to store a sign sequence $(a_0,a_1,\ldots,a_{n-1})$, and a function can return several values at once as a tuple. A piece of text is written between quotation marks, as in \code{"shortage"}; when displayed as an entry of a tuple, it appears between single quotes, as in \code{('shortage', 1)}.

A \emph{set} records membership only, as in Section~\ref{ch03:sec:sets}: order and repetition do not matter, so \code{\{1, 2, 2\}} is the same set as \code{\{1, 2\}}. The test \code{2 in s} is \code{True} when $2$ is a member of \code{s}, and \code{not in} tests the opposite. The union $s\cup t$ is written \code{s | t}, so \code{\{1, 2\} | \{2, 3\}} is \code{\{1, 2, 3\}}. The empty set is written \code{set()}, because empty braces \code{\{\}} mean an empty dictionary, described below. A loop \code{for x in s:} visits the members of \code{s} in no promised order; when the order matters, loop over \code{sorted(s)}, the list of the members in increasing order. For example, \code{sorted(\{3, 1, 2\})} is \code{[1, 2, 3]}.

A \emph{dictionary} is a table that pairs each \emph{key} with a value. After \code{owner = \{\}} creates an empty table, \code{owner[3] = 0} records the pair ``key $3$, value $0$,'' and \code{owner[3]} then looks the value up. The test \code{3 in owner} asks whether the key $3$ has an entry. Asking for \code{owner[5]} when the key $5$ has no entry stops the program with an error, whereas \code{owner.get(5)} simply gives \code{None}. Python prints the table as \code{\{3: 0\}}: each key, a colon, and its value. The official Python tutorial explains lists, tuples, sets and dictionaries in more detail~\cite{pystructures}.

\subsection*{Adding up and checking many cases at once}
Python can write a sum much as mathematics does. The loop that computed $A_1$ above can be replaced by the single expression
\par\noindent\begin{minipage}{\linewidth}
\begin{lstlisting}
sum(a[j] * a[j + 1] for j in range(3))
\end{lstlisting}
\end{minipage}\par
which reads like $\sum_{j=0}^{2}a_ja_{j+1}$ and has the same value, $1$. Similarly, \code{all(}\emph{test} \code{for s in range(1, n))} is \code{True} when the test holds for every $s$ with $1\le s\le n-1$, and \code{False} as soon as it fails for one. For example, \code{all(abs(correlation(a, s)) <= 1 for s in range(1, 4))} is \code{True} for \code{a = [1, 1, 1, -1]}, and \code{False} for \code{a = [1, 1, -1, -1]}, whose correlation at shift two is $A_2=-2$ (Section~\ref{ch14:sec:aperiodic}). When the range is empty, as \code{range(1, 1)} is, the result is \code{True}: a statement about every member of an empty collection is vacuously true (Section~\ref{ch02:sec:contrapositive}). Finally, \code{sum(1 for x in xs if }\emph{test}\code{)} adds $1$ for each member \code{x} of the list \code{xs} that passes the test, so it counts those members; for instance, \code{sum(1 for x in [3, 8, 5, 10] if x > 4)} is $3$.

Two more conventions appear below. Python ignores everything on a line after the sign \code{\#}, so this sign starts a comment for human readers; and a line such as \code{from fractions import Fraction} makes one tool from the standard library available to the program, here \code{Fraction} for exact rational arithmetic (Section~\ref{appD:sec:fractions}).
