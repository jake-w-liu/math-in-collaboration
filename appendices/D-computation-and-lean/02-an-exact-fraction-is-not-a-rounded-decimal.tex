\section{An exact fraction is not a rounded decimal}
Use \code{Fraction} when the intended inputs are rational. It stores a numerator and denominator and performs rational arithmetic rather than immediately converting to a floating-point approximation~\cite{pyfractions}.
\par\noindent\begin{minipage}{\linewidth}
\begin{lstlisting}
from fractions import Fraction
x = Fraction(1, 3)
y = (x * x + 1) / 3
print(y)
\end{lstlisting}
\end{minipage}\par

This prints \code{10/27}, the iterate $x_2$ from Chapter~12. Write \code{Fraction(1, 10)} for the exact rational number one tenth. Writing \code{0.1} instead gives Python's floating-point approximation of one tenth, which is not exactly equal to it; \code{Fraction(0.1)} would faithfully record that slightly different number.

The sign-sequence counts below use integer arithmetic, and the iteration checks use fractions, so no rounding occurs anywhere. Exact arithmetic removes one source of doubt, but not all of them: it does not prove that a loop examines exactly the intended objects, or that the mathematical assumptions behind the experiment hold. Exact arithmetic and a correct model are separate requirements.

\subsection*{Running a program}
Save a program in a plain text file whose name ends in \code{.py}, for example \code{signs.py}. Open a terminal, move to the folder containing the file (for example with \code{cd path/to/folder}, using the actual location), and run the file with \code{python3 signs.py}; on some systems the command is \code{python} instead. You can check which interpreter is installed with \code{python3 --version}.

Short calculations can also be typed at Python's interactive prompt, which appears after you type \code{python3} with no file name. The prompt is usually displayed as \code{>>>}. Type only the text after the prompt, and do not copy the prompt characters into a file. The terminal's own prompt expects commands that start programs, while Python's prompt expects Python statements; an error caused by typing into the wrong one says nothing about the mathematics being tested.
