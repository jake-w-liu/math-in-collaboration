\section{Structures, what proofs use, and changes of description}\label{appE:sec:structures}
Almost every object in this book is a set with something extra attached, which Section~\ref{ch06:sec:structure} calls a \emph{structure}. The set says which objects a question is about (Chapter~\ref{ch:maps}). A \emph{relation} says which pairs of objects are linked or compared (Section~\ref{ch06:sec:differences}); ``$a$ is congruent to $b$ modulo $m$'' and ``$u$ is adjacent to $v$'' are examples. An \emph{operation}, such as addition, combines two elements of a set into one element of the same set (Section~\ref{ch06:sec:structure}). A function, also called a map, sends each object of one set to an object of another (Section~\ref{ch03:sec:functions}), and so lets us carry a question from one description to another.

The extra structure decides which questions can even be asked.
\begin{itemize}
\item Addition and scaling let us form linear combinations of vectors (Chapter~\ref{ch:linear}).
\item The order of the natural numbers lets us pick out a smallest or a largest object. Every nonempty set of natural numbers has a smallest member (the well-ordering property of Sections~\ref{ch04:sec:contrapositive} and~\ref{ch05:sec:not-circular}), and every nonempty finite set of natural numbers also has a largest member. Chapter~\ref{ch:graphs} uses these facts to choose a shortest walk between two vertices that are joined by some walk, and a longest directed path in a nonempty finite directed graph.
\item A distance lets us say that one point approximates another, and so lets us speak of limits (Chapter~\ref{ch:limits}).
\item A probability on a finite set of outcomes lets us take weighted averages (Chapter~\ref{ch:probability}).
\end{itemize}
In a set with no distance, for instance, the phrase ``$x_n$ gets close to $x_*$'' has no meaning.

Habit~3 (Section~\ref{ch03:sec:images}) asks which information a proof actually uses. For the main theorems of the book the answers are short.
\begin{itemize}
\item The proofs of Hall's theorem (Chapter~\ref{ch:hall}) use only which students accept which tasks, and how many members various finite sets have. They never use what the students and the tasks actually are. That is why the theorem applies to every finite bipartite graph, whatever its vertices stand for.
\item The proof of the contraction theorem (Theorem~\ref{thm:banach}) works entirely with distances. Besides the facts that the space is nonempty and that $T$ maps it into itself, it uses the contraction inequality, completeness, and the three requirements of a metric, above all the triangle inequality. It never adds two points or multiplies a point by a number. That is why it works in metric spaces that have no addition at all.
\item The proof of the Cauchy--Schwarz inequality (Theorem~\ref{thm:cs}) uses only three properties of the dot product: linearity in each argument, symmetry, and positivity. It never looks at individual coordinates. So the same inequality, with the same proof, holds for any other way of multiplying two vectors to get a number, as long as this product has the same three properties and the length of a vector $u$ is defined in the same way, as the square root of the product of $u$ with itself. For example, on $\RR^2$ the product that sends $u$ and $v$ to $2u_1v_1+u_2v_2$ is symmetric and linear in each argument. It is also positive: the product of $u$ with itself is $2u_1^2+u_2^2$, which is never negative and is zero only when $u=0$. So $|2u_1v_1+u_2v_2|\le\sqrt{2u_1^2+u_2^2}\,\sqrt{2v_1^2+v_2^2}$ for all $u,v\in\RR^2$, with no new work.
\item Chapter~\ref{ch:signs} first translates a condition on a sign sequence, that all its periodic correlations at nonzero shifts are zero, into a condition on a matrix: different rows of its circulant matrix are orthogonal (Proposition~\ref{ch14:prop:rows}). Two arguments then restrict the order of such a matrix, that is, its number of rows. Adding up all the correlations shows that the order of the matrix is a perfect square (Section~\ref{ch14:sec:square}), and this argument relies on the circulant pattern. Comparing three rows shows that the order is divisible by four when it is greater than $2$ (Lemma~\ref{thm:hadamardorder}). This second argument uses only two facts, that the entries are $\pm1$ and that different rows are orthogonal, and these two facts are exactly what makes a square matrix a Hadamard matrix (Section~\ref{ch14:sec:circulant}). So it holds for every Hadamard matrix, circulant or not.
\end{itemize}
Noticing what a proof does \emph{not} use tells you where its conclusion might reach further. It is a guide for guessing, not a proof: every proposed extension still has to be checked against the argument, line by line.

Many steps in the book change the description of a problem without changing the problem itself, and Habit~6 (Section~\ref{ch06:sec:order}) asks what such a change preserves. A new description helps only when we know exactly what it keeps and what it throws away. Here are four changes of description from the book.
\begin{itemize}
\item \emph{An inverse loses nothing.} If $f$ has an inverse $h$, then every input can be recovered from its output, as $x=h(f(x))$. In particular, $f(x)=f(y)$ gives $x=h(f(x))=h(f(y))=y$, so different inputs never share an output, and a question about inputs can be answered by looking at outputs (Section~\ref{ch03:sec:injsurj}).
\item \emph{A quotient forgets on purpose.} Passing from an integer $a$ to its residue class $[a]_m$ forgets everything about $a$ except its remainder on division by $m$. This is safe only for rules that give the same answer for every representative of a class, which is why well-definedness has to be checked (Section~\ref{ch06:sec:well-defined}).
\item \emph{A matrix turns a linear map into a table of numbers.} Column $j$ of the matrix records where the map sends the standard basis vector $e_j$ (Section~\ref{ch10:sec:linearmaps}), and composing two linear maps corresponds to multiplying their matrices (Section~\ref{ch10:sec:product}).
\item \emph{An indicator turns an event into a quantity.} The indicator of an event is the random variable that equals $1$ when the event occurs and $0$ when it does not. Counting how many events occur then becomes adding numbers, and linearity of expectation applies (Section~\ref{ch13:sec:indicators}).
\end{itemize}
These constructions are quite different, but each one gives a language in which the step we need is easier to state and to justify.
