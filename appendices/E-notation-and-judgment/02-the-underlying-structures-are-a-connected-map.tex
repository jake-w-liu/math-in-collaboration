\section{The structures behind the book, and what each one allows}\label{appE:sec:structures}
Almost every object in this book is a set with something extra attached, which Section~\ref{ch06:sec:structure} calls a \emph{structure}. The set says which objects a question is about (Chapter~\ref{ch:maps}). A \emph{relation} says which pairs of objects are linked or compared; ``is congruent to modulo $m$'' and ``is adjacent to'' are examples (Section~\ref{ch06:sec:differences}). An \emph{operation}, such as addition, combines two objects into a third (Section~\ref{ch06:sec:structure}). A function, also called a map, sends each object of one set to an object of another (Section~\ref{ch03:sec:functions}), and so lets us carry a question from one description to another.

The extra structure decides which questions can even be asked.
\begin{itemize}
\item Addition and scaling let us form linear combinations of vectors (Chapter~\ref{ch:linear}).
\item The order of the natural numbers lets us pick out a smallest or a largest object. Every nonempty set of natural numbers has a smallest member, and every nonempty finite set of natural numbers also has a largest member. Chapter~\ref{ch:graphs} uses these facts to choose a shortest walk between two vertices that are joined by some walk, and a longest directed path in a nonempty finite directed graph.
\item A distance lets us say that one point approximates another, and so lets us speak of limits (Chapter~\ref{ch:limits}).
\item A probability on a finite set of outcomes lets us take weighted averages (Chapter~\ref{ch:probability}).
\end{itemize}
Without the right structure, such a question has no meaning. In a set with no distance, for instance, the phrase ``$x_n$ gets close to $x_*$'' says nothing.

Habit~3 (Chapter~\ref{ch:maps}) asks which information a proof actually uses. For the main theorems of the book the answers are short, and they are revealing.
\begin{itemize}
\item The proofs of Hall's theorem (Chapter~\ref{ch:hall}) use only which students accept which tasks, and how many members various finite sets have. They never use what the students and the tasks actually are. That is why the theorem applies to every finite bipartite graph, whatever its vertices stand for.
\item The proof of the contraction theorem (Theorem~\ref{thm:banach}) works entirely with distances. It uses the contraction inequality, completeness, and the three requirements of a metric, above all the triangle inequality. It never adds two points or multiplies a point by a number. That is why it works in metric spaces that have no addition at all.
\item The proof of the Cauchy--Schwarz inequality (Theorem~\ref{thm:cs}) uses only three properties of the dot product: linearity in each argument, symmetry, and positivity. It never looks at individual coordinates. So the same inequality, with the same proof, holds for any other way of multiplying two vectors to get a number, as long as that product has these three properties and lengths are defined from it in the same way, as $\sqrt{u\cdot u}$.
\item Chapter~\ref{ch:signs} first translates a condition on a sign sequence, that all its periodic correlations at nonzero shifts are zero, into a condition on a matrix: different rows of its circulant matrix are orthogonal (Proposition~\ref{ch14:prop:rows}). Two arguments then restrict the order of such a matrix, that is, its number of rows. Adding up all the correlations shows that the order of the matrix is a perfect square (Section~\ref{ch14:sec:square}), and this argument relies on the circulant pattern. Comparing three rows shows that the order is divisible by four when it is greater than $2$ (Lemma~\ref{thm:hadamardorder}). This second argument uses only two facts, that the entries are $\pm1$ and that different rows are orthogonal. So it holds for every Hadamard matrix, circulant or not, that is, for every square matrix with entries $\pm1$ whose different rows are orthogonal.
\end{itemize}
Noticing what a proof does \emph{not} use tells you where its conclusion might reach further. It is a guide for guessing, not a proof: every proposed extension still has to be checked against the argument, line by line.

Many steps in the book change the description of a problem without changing the problem itself, and Habit~6 (Chapter~\ref{ch:structure}) asks what such a change preserves. A new description helps only when we know exactly what it keeps and what it throws away. Here are four changes of description from the book.
\begin{itemize}
\item \emph{An inverse loses nothing.} If $f$ has an inverse $h$, then $f(x)=f(y)$ gives $x=h(f(x))=h(f(y))=y$. Equal outputs come only from equal inputs, so a question about inputs can be answered by looking at outputs (Section~\ref{ch03:sec:injsurj}).
\item \emph{A quotient forgets on purpose.} Passing from an integer $a$ to its residue class $[a]_m$ forgets everything about $a$ except its remainder on division by $m$. This is safe only for rules that give the same answer for every representative of a class, which is why well-definedness has to be checked (Section~\ref{ch06:sec:well-defined}).
\item \emph{A matrix turns a linear map into a table of numbers.} Column $j$ of the matrix records where the map sends the standard basis vector $e_j$ (Section~\ref{ch10:sec:linearmaps}), and composing two linear maps corresponds to multiplying their matrices (Section~\ref{ch10:sec:product}).
\item \emph{An indicator turns an event into a quantity.} The indicator of an event is the random variable that equals $1$ when the event occurs and $0$ when it does not. Counting how many events occur then becomes adding numbers, and linearity of expectation applies (Section~\ref{ch13:sec:indicators}).
\end{itemize}
These constructions are quite different, but each one gives a language in which the step we need is easier to state and to justify.
