\section{Testing the first guess}\label{ch18:sec:guess}
A natural first guess is that small update errors do no lasting harm: if every $\eps_n$ is small, the points $y_n$ should still converge to $x_*$. Before trying to prove a guess, it pays to try to break it. A short exchange with an AI assistant might go like this.

\textbf{Reader:} I expect that small update errors still give convergence to $x_*$. Before I try to prove this, try to disprove it.

\textbf{Assistant:} A constant bias can shift the limit. Take $T(x)=qx$ on $\RR$, whose fixed point is $0$, and add the same small number $\eta>0$ at every update: $y_{n+1}=qy_n+\eta$. Then $y_n$ approaches $\eta/(1-q)$, not $0$, however small $\eta$ is.

\textbf{Reader:} Then convergence is the wrong target. Is there an error bound that still holds? And can it tell apart errors that stay bounded from errors that tend to zero?

\textbf{Assistant:} Start by bounding the distance from the next point to $x_*$ by $q$ times the present distance plus the update error. Then apply that bound over and over.

Neither reply has been checked yet. The first is a counterexample built on a \emph{constant bias}, an error that is the same at every update. Its hypotheses are easy to check: $|qx-qy|=q|x-y|$, so $T$ is a contraction with factor $q$; its only fixed point is $0$, because $qx=x$ gives $(1-q)x=0$; and every update error is $|y_{n+1}-T(y_n)|=|qy_n+\eta-qy_n|=\eta$, which can be as small as we like. With $q=1/2$, $\eta=1$ and $y_0=0$, the points
\[
 0,\ 1,\ \tfrac32,\ \tfrac74,\ \tfrac{15}8,\ \tfrac{31}{16},\ \ldots
\]
seem to approach $2=\eta/(1-q)$ rather than $0$. A few terms do not prove a limit, so Section~\ref{ch18:sec:sharp} proves an exact formula for $y_n$. The second reply is a plan for a proof, which Section~\ref{ch18:sec:onestep} carries out.

The counterexample has changed the question. We now ask how far from $x_*$ the points can be, when that distance still tends to zero, and, when it does not, where the points end up. The constant bias shows that these questions are separate: there the distance stays bounded but does not tend to zero, and the points converge to a different point. Habit~2 (Section~\ref{sec:magnitude}) asks us to compare such a change with the statement contract: the hypotheses are the same, but the conclusion is now a more modest one, an error bound.

\pauseq{A calculator keeps two decimal places and always rounds down. It runs the update $x\mapsto(x+1)/2$, whose fixed point is $1$, starting from $0$. Each rounding error is less than $0.01$. Do the stored values converge to $1$?}{No. The stored values are $0,\ 0.5,\ 0.75,\ 0.87,\ 0.93,\ 0.96,\ 0.98,\ 0.99,\ 0.99,\ \ldots$; for instance, $(0.75+1)/2=0.875$ is stored as $0.87$. From $0.99$ the exact update gives $0.995$, which is stored as $0.99$ again, so the values stay at distance $0.01$ from the fixed point. Rounding down acts like a small bias that always pushes in the same direction.}
