\section{The question that starts the project}\label{ch18:sec:question}
The contraction theorem of Chapter~\ref{ch:contraction} is about exact updates: each new point is $x_{n+1}=T(x_n)$, computed without any error. Real computations are rarely that clean. A computer keeps only finitely many digits, so it rounds each value of $T$ before storing it; a calculator that keeps two decimal places might store $0.87$ where the exact value is $0.875$. Measurements, too, have limited precision. In each case the new point is close to $T$ of the old point, but not equal to it. Does the iteration still approach the fixed point? And if not, how far from it can it end up?

This makes a good first investigation: it changes one feature of a theorem we already understand and keeps everything else. The bounds we reach are standard; what matters is how the investigation proceeds.

\subsection*{The setting}
Throughout the chapter, $(X,d)$ is a nonempty complete metric space, and $T:X\to X$ is a contraction with factor $q$, where $0<q<1$:
\[
 d(Tx,Ty)\le q\,d(x,y)\qquad\text{for all }x,y\in X.
\]
Asking for $q>0$ costs nothing, because a contraction with factor $0$ satisfies $d(Tx,Ty)\le0\le\frac12d(x,y)$ and so is also one with factor $1/2$; in return, every power $q^k$ below is positive. By Theorem~\ref{thm:banach}, $T$ has exactly one fixed point, which we call $x_*$.

In place of the exact iterates we now have points $y_0,y_1,y_2,\ldots$ of $X$, starting anywhere, and nonnegative numbers $\eps_0,\eps_1,\eps_2,\ldots$ such that
\[
 d(y_{n+1},T(y_n))\le\eps_n\qquad\text{for every }n\in\NN.
\]
The point $y_{n+1}$ is what the update actually produced when it should have produced $T(y_n)$, and $\eps_n$ bounds the error made in that update. We call $\eps_n$ the \emph{update error} at step~$n$ (strictly, it is an upper bound for that error, which is all we need). If every $\eps_n$ is zero, we are back to the exact iteration. Apart from these bounds we assume nothing: the errors need not follow any pattern, and they are not assumed to be random.

One assumption is easy to overlook: every $y_n$ must be a point of $X$, which an error bound alone cannot guarantee. If $X=[0,1]$ and a computed value is $-0.001$, then $d(y_{n+1},T(y_n))$ is not even defined, and $T$ cannot be applied at the next step. In an application, $y_n\in X$ must be checked separately, like the self-map condition of Section~\ref{ch12:sec:iteration}.
