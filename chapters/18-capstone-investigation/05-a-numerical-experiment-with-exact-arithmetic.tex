\section{A numerical experiment with exact arithmetic}
Choose $T(x)=(3x+1)/4$, whose fixed point is $1$, and use the biased update
\[
 y_{n+1}=\frac{3y_n+1}{4}+\frac1{100},\qquad y_0=0.
\]
The constants are $q=3/4$ and $\eta=1/100$. The approximate recurrence is affine:
\[
 y_{n+1}=\frac34 y_n+\frac{13}{50}.
\]
Its own fixed point $y$ solves $y=\frac34y+\frac{13}{50}$, so $\frac14y=\frac{13}{50}$ and $y=26/25$. As in Chapter~5, track the distance from this point: put $z_n=y_n-26/25$. Subtracting $26/25=\frac34\cdot\frac{26}{25}+\frac{13}{50}$ from the recurrence gives
\[
 z_{n+1}=\frac34 z_n,\qquad z_0=0-\frac{26}{25}=-\frac{26}{25},
\]
so $z_n=-\frac{26}{25}\left(\frac34\right)^n$ by induction, and therefore
\[
 y_n=\frac{26}{25}\left(1-\left(\frac34\right)^n\right).
\]
To apply Theorem~\ref{thm:inexact}, note that the initial error is $e_0=|0-1|=1$, the contraction factor is $q=3/4$, and every update error equals $\eta=1/100$, so $\eta/(1-q)=(1/100)/(1/4)=1/25$.
The theorem's error certificate is
\[
 \abs{y_n-1}\le
 \left(\frac34\right)^n+
 \frac1{25}\left(1-\left(\frac34\right)^n\right).
\]
Notice that the true error can first decrease toward zero and later increase toward $1/25$. A plot that stops near the smallest error would obscure the bias. The formula and bound tell us what a finite plot alone cannot establish.

A short program in Appendix~\ref{app:practical} carries out this experiment with exact rational arithmetic: it computes the iterates, checks the closed form at every index, and compares the exact error with the exact certificate. Decimals are used only for display. Changing the pattern of the update errors gives further experiments: compare a constant bias, errors of alternating sign, and errors that tend to zero. The theorem predicts a bound in all three cases, but convergence to the original fixed point only when the errors tend to zero.

\subsection*{What ``sharp'' means in this example}
Suppose someone proposes replacing the eventual error factor $1/(1-q)$ by a smaller constant $K$ that should work for every allowed iteration with this fixed $q$. Choose $\eta>0$ in the constant-bias example. Its actual error tends to $\eta/(1-q)$, which is strictly larger than $K\eta$. Thus sufficiently late errors exceed the proposed smaller bound. One permitted example refutes the universal improvement.

This does not say the original bound is attained in every application. In the biased example approaching $26/25$, the iteration starts below the fixed point $1$ while the bias pushes it upward, so these two effects partly cancel; the certificate, built from the triangle inequality, adds their sizes instead. Concretely, the true error is $\bigl|\frac1{25}-\frac{26}{25}\bigl(\frac34\bigr)^n\bigr|$, while the certificate equals $\frac1{25}+\frac{24}{25}\bigl(\frac34\bigr)^n$, so the certificate is conservative. A bound is sharp over a class when the class contains an example preventing a uniformly stronger bound. For a particular smaller class with additional structure, an improvement may still be possible. That distinction supplies a precise next research question: what extra assumption would rule out the example that obstructs an improved constant?
