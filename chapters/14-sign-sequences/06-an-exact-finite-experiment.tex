\section{An exact finite experiment}\label{ch14:sec:experiment}
A sign sequence of length $n$ is fixed by $n$ independent choices of sign, so there are $2^n$ of them, and for small $n$ a computer can examine every one. The table below shows the result of such an exhaustive search for $1\le n\le13$, produced directly from the definitions by the short program in Section~\ref{appD:sec:experiments}; only integers are involved, so the arithmetic is exact. For each length the search counts
\begin{itemize}
\item the Barker sequences;
\item the sequences with $C_s=0$ for every shift $s$ with $1\le s\le n-1$, which by Section~\ref{ch14:sec:circulant} are exactly the first rows of circulant Hadamard matrices.
\end{itemize}
Each sequence is counted separately: a sequence, its negative, its reversal (the same entries in the opposite order), and its rotations all count as different sequences whenever they are different lists.

\begin{center}
\begin{tabular}{@{}r rr@{}}\toprule
Length $n$ & Barker sequences & Sequences with $C_s=0$ for $1\le s\le n-1$\\\midrule
1&2&2\\2&4&0\\3&4&0\\4&8&8\\5&4&0\\6&0&0\\7&4&0\\8&0&0\\9&0&0\\10&0&0\\11&4&0\\12&0&0\\13&4&0\\\bottomrule
\end{tabular}
\end{center}

For these thirteen lengths the search examines every case, so, provided the program is correct, the table is complete. About any other length it says nothing, and the search cannot be pushed much further, because each additional position doubles the work. Length $64$, which Proposition~\ref{thm:circulantnecessary} leaves open, has $2^{64}>1.8\cdot10^{19}$ sign sequences; at a billion per second, that single length would take more than $580$ years. And even a far faster computer could check only finitely many of the infinitely many lengths. Only a proof can settle every length.

Every count agrees with what we have proved, and several patterns are explained by our results.
\begin{itemize}
\item The last column is zero at every length except $1$ and $4$, as Proposition~\ref{thm:circulantnecessary} predicts: below $16$ it allows only the orders $1$ and $4$.
\item For the odd lengths greater than $1$ there is a simpler explanation (the pause at the end of Section~\ref{ch14:sec:periodic}): every periodic correlation is odd, so none can be zero.
\item Every count is even. Negating every sign changes no correlation, because each is a sum of pair products and negation does not change pair products (Section~\ref{ch06:sec:wlog}; Exercise~\ref{ex:14.2}). So whenever $a$ is counted in a column, so is $-a$, and $-a\ne a$, since $a_0=-a_0$ would force $a_0=0$. Hence the sequences counted in each entry split into pairs $\{a,-a\}$.
\end{itemize}
Other features do not follow from anything proved so far, such as the absence of Barker sequences of lengths $6$, $8$, $9$, $10$, and $12$; for the even lengths among these, Section~\ref{ch14:sec:research} quotes a known result that accounts for the zeros.
