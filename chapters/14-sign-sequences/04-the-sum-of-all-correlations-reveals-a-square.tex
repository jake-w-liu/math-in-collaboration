\section{The sum of all correlations reveals a square}\label{ch14:sec:square}
Which lengths $n$ allow a sign sequence whose periodic correlations at all nonzero shifts are zero? A first restriction comes from adding up all the periodic correlations, including $C_0$: the total depends only on the sum of the entries,
\[
r=\sum_{j=0}^{n-1}a_j=a_0+a_1+\cdots+a_{n-1}.
\]
Each row of the circulant matrix contains every entry of $a$ once, so $r$ is also the sum of the entries in any row, and we call it the \emph{row sum}. For $(1,1,1,-1)$, the row sum is $r=2$.

Look first at $n=3$, with unknown entries $a_0,a_1,a_2$:
\begin{align*}
 C_0&=a_0a_0+a_1a_1+a_2a_2,\\
 C_1&=a_0a_1+a_1a_2+a_2a_0,\\
 C_2&=a_0a_2+a_1a_0+a_2a_1.
\end{align*}
Together these contain each of the nine products $a_ja_k$, with $j,k$ between $0$ and $2$, exactly once (with $a_0a_1$ and $a_1a_0$ counted as different products). Adding the display row by row gives $C_0+C_1+C_2$. Adding it column by column instead, the first column is $a_0a_0+a_0a_1+a_0a_2=a_0(a_0+a_1+a_2)$, and the other two are $a_1(a_0+a_1+a_2)$ and $a_2(a_0+a_1+a_2)$. So
\[
C_0+C_1+C_2=(a_0+a_1+a_2)^2=r^2.
\]

The same idea works for every $n$: the total is a table of $n^2$ products, one row for each shift $s$ and one column for each position $j$, and we may add it column by column instead of row by row:
\begin{align*}
\sum_{s=0}^{n-1}C_s
&=\sum_{s=0}^{n-1}\sum_{j=0}^{n-1}a_j a_{(j+s)\bmod n}
 =\sum_{j=0}^{n-1}\sum_{s=0}^{n-1}a_j a_{(j+s)\bmod n}\\
&=\sum_{j=0}^{n-1}a_j\left(\sum_{s=0}^{n-1}a_{(j+s)\bmod n}\right)\\
&=\sum_{j=0}^{n-1}a_j\left(\sum_{k=0}^{n-1}a_k\right)
 =\sum_{j=0}^{n-1}a_j\,r=r\sum_{j=0}^{n-1}a_j=r^2.
\end{align*}
\begin{itemize}
\item The first line writes out each $C_s$ and changes the order of summation.
\item The second pulls out $a_j$, which does not depend on $s$.
\item The third is the key step. Fix $j$. As $s$ runs through $0,1,\ldots,n-1$, the position $(j+s)\bmod n$ runs through $j,\ldots,n-1$ and then wraps around to $0,\ldots,j-1$, visiting every position once. So the inner sum is the sum of all the entries in a different order, which is $r$.
\item Finally, $r$ does not depend on $j$, so it comes out of the outer sum.
\end{itemize}
For $(1,1,1,-1)$ the identity says $4+0+0+0=2^2$. It holds for every sequence: $(1,1,-1,-1)$ has $r=0$ and $C_0=4$, $C_1=0$, $C_2=-4$, $C_3=0$, which add up to $0=0^2$.

The identity holds for any real numbers $a_0,\ldots,a_{n-1}$; the signs are used only afterward, to know that $C_0=n$ and that $r$ is an integer. Tracking which hypothesis is used where, as Habit~3 (Section~\ref{ch03:sec:images}) asks, shows which parts of an argument survive in a more general setting.

Now suppose that $C_s=0$ for every shift $s$ with $1\le s\le n-1$. Then the left side is just $C_0=n$, so
\begin{equation}
n=r^2.\label{eq:squareorder}
\end{equation}
Since $r$ is a sum of signs, it is an integer, so $n$ must be a perfect square. By Proposition~\ref{ch14:prop:rows}(b), the first row of a circulant Hadamard matrix of order $n$ is such a sequence, so the order of every circulant Hadamard matrix is a perfect square: in the language of Section~\ref{ch02:sec:implication}, this is a \emph{necessary} condition, and it covers every length at once.
