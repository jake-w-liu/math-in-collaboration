\section{Contraposition and vacuous truth}\label{ch02:sec:contrapositive}
The \emph{contrapositive} of $P\Rightarrow Q$ is $\neg Q\Rightarrow\neg P$: if the conclusion fails, then the hypothesis must have failed too. An implication and its contrapositive are \emph{logically equivalent}: each is true exactly when the other is, whatever the statements $P$ and $Q$ are. ``Logically'' signals that this follows from the form of the statements alone, as the following argument shows.
\begin{itemize}
\item Suppose $P\Rightarrow Q$ is true, and suppose $Q$ fails. If $P$ held, the implication would force $Q$ to hold, which it does not. So $P$ fails. This proves $\neg Q\Rightarrow\neg P$.
\item Suppose $\neg Q\Rightarrow\neg P$ is true, and suppose $P$ holds. If $Q$ failed, the contrapositive would force $P$ to fail, which it does not. So $Q$ holds. This proves $P\Rightarrow Q$.
\end{itemize}
The second argument concludes that $Q$ holds because the possibility that $Q$ fails has been ruled out. That step uses the principle that every statement is either true or false, so ruling out one possibility leaves the other. Ordinary mathematics accepts this principle, and so do we.

Do not confuse the contrapositive with the converse. ``Divisible by four implies even'' is equivalent to its contrapositive, ``not even implies not divisible by four'': for example, $7$ is not even, so $7$ is not divisible by four. It is \emph{not} equivalent to its converse, ``even implies divisible by four,'' which fails at $n=6$.

The contrapositive is often the easier version to prove. Section~\ref{ch04:sec:contrapositive} proves the harder direction of ``$n$ is even if and only if $n^2$ is even'' (Lemma~\ref{thm:parity-square}), namely ``if $n^2$ is even, then $n$ is even,'' through its contrapositive, ``if $n$ is not even, then $n^2$ is not even.'' The new hypothesis is about $n$ itself rather than about $n^2$, and since an integer that is not even is odd (Lemma~\ref{ch04:lem:even-or-odd}), it lets us write $n=2k+1$, a form we can calculate with.

\subsection*{Vacuous truth}
What happens when the hypothesis of an implication can never hold? Consider the statement
\begin{center}
\emph{Every integer that is both even and odd is larger than $100$.}
\end{center}
As an implication: for every integer $n$, if $n$ is both even and odd, then $n>100$. A counterexample would have to be an integer that is both even and odd and at most $100$. But no integer is both even and odd: if $n=2k$ and $n=2\ell+1$ for integers $k$ and $\ell$, then $2(k-\ell)=1$, so $k-\ell=1/2$, which is impossible because $k-\ell$ is an integer and $1/2$ is not. So there is no counterexample, and the statement counts as true, in agreement with Section~\ref{ch02:sec:connectives}: an implication fails only when its hypothesis holds and its conclusion fails.

A statement of this kind is called \emph{vacuously true}: it is true because there is nothing for it to be about. It does not tell us that an integer which is both even and odd exists, nor anything about integers larger than $100$; ``every integer that is both even and odd is smaller than $0$'' is vacuously true as well.

A theorem whose hypotheses can never all hold at once is vacuously true in the same way: its proof may be correct and still tell us nothing. Suppose an assistant proves a result about ``every real number $x$ with $x^2<0$.'' No real number has a negative square, so the result is vacuously true however impressive its conclusion looks. Before relying on a theorem, check that at least one object satisfies all of its hypotheses. Vacuous truth returns in Chapter~\ref{ch:maps}, where it explains why the empty set, the set with no members, is contained in every set.
