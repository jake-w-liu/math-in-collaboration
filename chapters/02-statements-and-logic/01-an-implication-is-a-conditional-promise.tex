\section{An implication is a conditional promise}\label{ch02:sec:implication}
In mathematics, a \emph{statement} is a sentence that is either true or false. ``Seven is odd'' is a true statement, and ``$2+2=5$'' is a false one. A sentence such as ``$n$ is even'' is not yet true or false, because it depends on the value of $n$; it becomes a statement as soon as a value of $n$ is fixed. A question such as ``Is $15$ odd?'' or an instruction such as ``Add $3$ to both sides'' is not a statement at all.

Many mathematical statements have the form ``if \ldots, then \ldots.'' Our first example of such a statement needs one new word. An integer $n$ is \emph{divisible by} an integer $d$ when $n=dk$ for some integer $k$. For example, $20$ is divisible by four, because $20=4\cdot5$ and $5$ is an integer. On the other hand, $6$ is not divisible by four: the equation $6=4k$ forces $k=6/4=3/2$, which is not an integer. As with even and odd numbers in Section~\ref{ch01:sec:definition}, the number $k$ is called a witness, and the requirement that it be an integer is essential.

Now consider the statement
\begin{center}
\emph{If an integer is divisible by four, then it is even.}
\end{center}
It has two parts. The part after ``if'' is the \emph{hypothesis}, the condition that is assumed. The part after ``then'' is the \emph{conclusion}, what is promised once the hypothesis holds. For an integer $n$, let $P$ stand for the statement ``$n$ is divisible by four'' and let $Q$ stand for the statement ``$n$ is even.'' A statement of the form ``if $P$, then $Q$'' is called an \emph{implication}. We write it $P\Rightarrow Q$ and read it ``$P$ implies $Q$.'' Like any statement, an implication can be true or false. Our sentence makes its promise for every integer $n$ at once; Section~\ref{ch02:sec:quantifiers} introduces a symbol for ``for every.''

The promise is easy to prove. Let $n$ be an integer that is divisible by four. Then $n=4k$ for some integer $k$, and so $n=2(2k)$. The number $2k$ is an integer, so $n$ is twice an integer. By the definition of even (Definition~\ref{def:parity}), $n$ is even.

Notice what the implication does \emph{not} say. It makes no promise about an integer that is not divisible by four. Such an integer may be even, like $6$, or odd, like $7$, and both possibilities are consistent with the statement. A common reading error is to run the implication backward, as if it also said that every even integer is divisible by four.

That backward statement has its own name. The \emph{converse} of $P\Rightarrow Q$ is $Q\Rightarrow P$. Here the converse says ``if an integer is even, then it is divisible by four,'' and it is false: $6$ is even but, as we saw, not divisible by four. A statement and its converse are different promises, and one of them can be true while the other is false.

A particular input that shows a statement about every input to be false is called a \emph{counterexample}. For an implication, a counterexample is an input for which the hypothesis is true and the conclusion is false. The integer $6$ is a counterexample to the converse above: it satisfies the converse's hypothesis, because it is even, and it violates the converse's conclusion, because it is not divisible by four. One counterexample is enough. The converse claims to hold for \emph{every} integer, and a single failure shows that this claim is wrong.

So when you test an implication, only inputs that satisfy the hypothesis can reveal a failure. An input such as $7$, about which ``divisible by four implies even'' promises nothing, can never be a counterexample to it. Keep this in mind when you ask an assistant to test a claim. Inputs chosen at random often miss the hypothesis and so test nothing. Ask instead for inputs that satisfy the hypothesis, and then check whether each one satisfies the conclusion.

Sometimes an implication and its converse are both true. The statement $P\Leftrightarrow Q$, read ``$P$ if and only if $Q$,'' promises both $P\Rightarrow Q$ and $Q\Rightarrow P$. The phrase splits into two halves. ``$P$ if $Q$'' means $Q\Rightarrow P$. ``$P$ only if $Q$'' says that $P$ can hold only when $Q$ holds as well; in other words, whenever $P$ holds, so does $Q$, and that is $P\Rightarrow Q$. For example, ``an integer is divisible by four only if it is even'' is another way of saying ``divisible by four implies even.'' When $P\Leftrightarrow Q$ holds, we say that $P$ and $Q$ are \emph{equivalent}. To prove an ``if and only if'' statement, we prove the two implications separately.

For example, for every integer $n$,
\begin{center}
\emph{$n$ is even if and only if $n^2$ is even.}
\end{center}
One direction is a short calculation. If $n=2k$ for an integer $k$, then $n^2=4k^2=2(2k^2)$, which is twice an integer. The other direction is harder, because knowing that $n^2=2w$ for some integer $w$ gives no direct way to write $n$ itself as twice an integer. Section~\ref{ch02:sec:contrapositive} describes the idea that gets around this, and Lemma~\ref{thm:parity-square} in Chapter~\ref{ch:proof} carries out the proof.

\subsection*{A result applies only after its hypothesis is checked}
To use ``divisible by four implies even'' for the number $20$, we first check the hypothesis: $20=4\cdot5$, and $5$ is an integer. Only then does the result tell us that $20$ is even. Two ingredients are needed: the implication itself, proved once for all integers, and evidence that this particular number satisfies its hypothesis. Quoting the implication does not supply the evidence.

Here is what goes wrong when the check is skipped. Suppose an assistant writes: ``$30$ is even, because every integer divisible by four is even.'' The conclusion happens to be true, but the reason is not valid. The number $30$ is not divisible by four, since $30=4k$ would force $k=15/2$, so the result says nothing about $30$. A correct reason is simply $30=2\cdot15$.

\subsection*{Necessary and sufficient, stronger and weaker}
Two words describe the roles of $P$ and $Q$ in a true implication $P\Rightarrow Q$. We say that $P$ is a \emph{sufficient} condition for $Q$: knowing $P$ is enough to guarantee $Q$. We also say that $Q$ is a \emph{necessary} condition for $P$: $P$ cannot hold unless $Q$ holds too. So divisibility by four is sufficient for evenness, and evenness is necessary for divisibility by four. The converse, ``even implies divisible by four,'' fails, as $6$ shows, so evenness is not sufficient for divisibility by four. When $P\Leftrightarrow Q$ holds, $P$ is both necessary and sufficient for $Q$.

When every object satisfying $P$ also satisfies $Q$, but not the other way around, we call $P$ the \emph{stronger} condition and $Q$ the \emph{weaker} one. The stronger condition demands more, so it is harder to satisfy. Divisibility by four is stronger than evenness, because divisibility by four implies evenness but, as we just saw, not conversely. The same words are used for whole statements. A stronger statement promises more than a weaker one; for instance, a statement about every integer is stronger than the same statement about positive integers only.
