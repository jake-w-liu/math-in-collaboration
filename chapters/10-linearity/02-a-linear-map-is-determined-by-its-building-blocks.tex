\section{A linear map is determined by its building blocks}\label{ch10:sec:linearmaps}
A map $T:\RR^n\to\RR^m$ is \emph{linear} when it preserves both addition, in the sense of Section~\ref{ch06:sec:structure}, and multiplication by scalars:
\[
T(x+y)=T(x)+T(y)\qquad\text{and}\qquad T(cx)=cT(x)
\]
for all vectors $x,y\in\RR^n$ and all scalars $c$. The two conditions can be combined into one: $T$ is linear exactly when
\[
T(ax+by)=aT(x)+bT(y)\qquad\text{for all $x,y\in\RR^n$ and all $a,b\in\RR$.}
\]
Indeed, the two conditions give $T(ax+by)=T(ax)+T(by)=aT(x)+bT(y)$. Conversely, the combined condition with $a=b=1$ is preservation of addition, and with $b=0$ it says $T(ax)=aT(x)$. Taking $c=0$ in the second condition shows that a linear map sends the zero vector to the zero vector: $T(0)=T(0x)=0\,T(x)=0$ for any $x$.

A linear map sends every linear combination to the same combination of the outputs. For three vectors, split off the last term by preservation of addition, then use the combined condition on the first piece and scaling on the second:
\[
T(a_1v_1+a_2v_2+a_3v_3)=T(a_1v_1+a_2v_2)+T(a_3v_3)=a_1T(v_1)+a_2T(v_2)+a_3T(v_3).
\]
Splitting off one term at a time works for any number $k$ of terms (formally, by induction on $k$, as in Chapter~\ref{ch:induction}):
\[
T(a_1v_1+\cdots+a_kv_k)=a_1T(v_1)+\cdots+a_kT(v_k).
\]
In particular, writing $x=x_1e_1+\cdots+x_ne_n$ shows that every linear map $T:\RR^n\to\RR^m$ satisfies
\[
T(x)=x_1T(e_1)+x_2T(e_2)+\cdots+x_nT(e_n).
\]
So the $n$ vectors $T(e_1),\ldots,T(e_n)$ determine the output $T(x)$ at every one of the infinitely many inputs $x$. This is why a linear map can be recorded in a finite table of numbers.

Suppose, for example, that $T:\RR^2\to\RR^2$ is linear, with $T(e_1)=(1,1)$ and $T(e_2)=(1,-1)$, the basis vectors $w_1$ and $w_2$ of Section~\ref{ch10:sec:vectors}. Then
\[
T(x_1,x_2)=x_1(1,1)+x_2(1,-1)=(x_1+x_2,\,x_1-x_2),
\]
where $T(x_1,x_2)$ is short for $T\bigl((x_1,x_2)\bigr)$. A \emph{matrix} is a rectangular table of numbers. We record $T$ by the matrix whose first column is $T(e_1)$ and whose second column is $T(e_2)$:
\[
A=\begin{pmatrix}1&1\\1&-1\end{pmatrix},\qquad
Ax=\begin{pmatrix}x_1+x_2\\x_1-x_2\end{pmatrix}.
\]
Here $Ax$ stands for $T(x)$. A vector may be written horizontally, as $(x_1,x_2)$, or as a column, as in $Ax$; both name the same ordered list.

An \emph{$m$-by-$n$ matrix} has $m$ rows and $n$ columns. We write $A_{ij}$ for the entry in row $i$ and column $j$; the first subscript always names the row. For the matrix $A$ above, $A_{12}=1$ and $A_{22}=-1$. An $m$-by-$n$ matrix $A$ acts on a vector $x\in\RR^n$ and produces the vector $Ax\in\RR^m$ whose $i$th coordinate is
\[
(Ax)_i=\sum_{j=1}^n A_{ij}x_j=A_{i1}x_1+A_{i2}x_2+\cdots+A_{in}x_n\qquad(1\le i\le m).
\]
In words: to find the $i$th coordinate of $Ax$, multiply the entries of row $i$ by the matching coordinates of $x$, and add the products. We call this the \emph{row rule}. For example, take
\[
M=\begin{pmatrix}2&-1&3\\1&0&1\end{pmatrix}\qquad\text{and}\qquad x=(4,5,0).
\]
The first row gives $2\cdot4+(-1)\cdot5+3\cdot0=3$, and the second gives $1\cdot4+0\cdot5+1\cdot0=4$, so $Mx=(3,4)$. The input needs three coordinates, one for each entry of a row, and the output has one coordinate for each row. A matrix with as many rows as columns is called \emph{square}.

The row rule agrees with the way $A$ was built from its columns. For any $m$-by-$n$ matrix $A$, the $i$th coordinate of the combination
\[
x_1(\text{column $1$ of $A$})+x_2(\text{column $2$ of $A$})+\cdots+x_n(\text{column $n$ of $A$})
\]
is $x_1A_{i1}+x_2A_{i2}+\cdots+x_nA_{in}$, which is exactly $(Ax)_i$. So $Ax$ is this combination of the columns, with the coordinates of $x$ as coefficients; in the example, $Mx=4(2,1)+5(-1,0)+0(3,1)=(3,4)$. Taking $x=e_j$ shows that $Ae_j$ is column $j$ of $A$. Now, for any linear map $T:\RR^n\to\RR^m$, build the $m$-by-$n$ matrix $A$ whose column $j$ is $T(e_j)$. Then $Ax=x_1T(e_1)+\cdots+x_nT(e_n)=T(x)$. So $A$ records $T$ exactly; it is called the \emph{matrix of} $T$.

Conversely, every $m$-by-$n$ matrix $A$ gives a linear map $x\mapsto Ax$ from $\RR^n$ to $\RR^m$. Take $x,y\in\RR^n$ and scalars $a,b$. The $j$th coordinate of $ax+by$ is $ax_j+by_j$, so by the row rule the $i$th coordinate of $A(ax+by)$ is
\[
\sum_{j=1}^n A_{ij}(ax_j+by_j)=a\sum_{j=1}^n A_{ij}x_j+b\sum_{j=1}^n A_{ij}y_j,
\]
which is the $i$th coordinate of $aAx+bAy$. This holds for every $i$, so $A(ax+by)=aAx+bAy$.

The two constructions undo each other. The matrix of the map $x\mapsto Ax$ is $A$ itself, since its column $j$ is $Ae_j$. And the matrix of $T$ is the only matrix $B$ with $Bx=T(x)$ for every $x$, since for such $B$ column $j$ is $Be_j=T(e_j)$. Thus linear maps from $\RR^n$ to $\RR^m$ and $m$-by-$n$ matrices are two descriptions of the same objects, and we often say that a matrix maps $\RR^n$ to $\RR^m$.
