\section{A failed search exposes a shortage}\label{ch08:sec:shortage}
To say that a group of students is short of tasks, we need all the tasks the group accepts. For a set $S$ of students, let $N(S)$ be the set of tasks that at least one student of $S$ accepts, that is, the union of the sets $N(s)$ for $s$ in $S$. A task accepted by several students of $S$ is still only one member of $N(S)$: in the Ada--Ben graph, $N(\{\text{Ada},\text{Ben}\})=\{1,2\}\cup\{1\}=\{1,2\}$. For a single student, $N(\{s\})=N(s)$, and $N(\varnothing)=\varnothing$.

\subsection*{An example}
Let three students $a$, $b$, $c$ each accept exactly the tasks $1$ and $2$, let $M=\{a\text{--}1,\ b\text{--}2\}$, and run the complete search of Section~\ref{ch08:sec:search} from the root $x=c$. Write $A$ for the set of students it reaches, including $x$, and $B$ for the set of tasks it reaches.
Inspecting $c$ follows both of its edges, which are unmatched, and reaches task~$1$ with its owner $a$ and task~$2$ with its owner $b$. Inspecting $a$ and $b$ finds only the unmatched edges $a$--$2$ and $b$--$1$, whose tasks have already been reached. So the search fails, with $A=\{c,a,b\}$ and $B=\{1,2\}$. Here $|B|=|A|-1$, since each task of $B$ is held by a different student of $A$ and the root $c$ holds none, and $N(A)=B$, since the students of $A$ accept only tasks $1$ and $2$; three students who together accept two tasks cannot all be given different ones. The next proposition shows that this happens whenever a complete search fails.

\par\noindent\begin{minipage}{\linewidth}
\begin{proposition}\label{ch08:prop:shortage}
Let $M$ be a matching in a bipartite graph and let $x$ be an unmatched student. Suppose that the complete search from $x$ fails, and let $A$ and $B$ be the sets of students and tasks that it reached. Then
\[
N(A)=B\qquad\text{and}\qquad |N(A)|=|A|-1.
\]
\end{proposition}
\end{minipage}\par

\begin{proof}
We use properties (C1) and (C2) of a failed search from Section~\ref{ch08:sec:search}.

\emph{Step 1: $|B|=|A|-1$.} For each task $t$ in $B$, let $f(t)$ be the owner of $t$. By (C2), $t$ is used, so it has exactly one owner, and this owner is a reached student. It is not $x$, because $x$ is unmatched. So $f$ is a function from $B$ to $A\setminus\{x\}$. It is injective: if two different tasks $t$ and $t'$ had the same owner $s$, then $s$ would lie on two different edges $s$--$t$ and $s$--$t'$ of $M$. It is surjective: a student $s$ in $A$ other than $x$ can only have been reached by a move from the task it holds, so that task lies in $B$, and $f$ sends it to $s$. Hence $f$ is a bijection, and by Section~\ref{ch03:sec:injsurj}, $|B|=|A\setminus\{x\}|=|A|-1$.

\emph{Step 2: $N(A)=B$.} Every task $t$ in $B$ was reached by a move from some reached student $s$ along an edge $s$--$t$, so $t\in N(s)\subseteq N(A)$. Thus $B\subseteq N(A)$. Conversely, let $t$ be any task in $N(A)$, and choose a student $s\in A$ that accepts $t$.
\begin{itemize}
\item If the edge $s$--$t$ is unmatched, then $t$ has been reached, by (C1).
\item If the edge $s$--$t$ is matched, then $s$ is matched, so $s\ne x$, and $t$ is the task that $s$ holds. As in Step~1, $s$ was reached by a move from that task, so $t$ was reached before~$s$.
\end{itemize}
In both cases $t\in B$. Thus $N(A)\subseteq B$, and so $N(A)=B$.

Combining the two steps gives $|N(A)|=|B|=|A|-1$.
\end{proof}

In the smallest case the root $x$ accepts no task. The search fails at once, with $A=\{x\}$ and $B=\varnothing$, and indeed $N(A)=\varnothing=B$ and $|N(A)|=0=|A|-1$.

Step~1 compares $A$ only with the tasks the search happened to reach; Step~2, which needs the completeness of the search, counts \emph{all} the tasks the students of $A$ accept. Suppose the search in the example had stopped right after reaching task~$1$ and its owner~$a$, before following the edge $c$--$2$. Then $A=\{c,a\}$ and $B=\{1\}$, and still $|B|=|A|-1$. But $N(A)=\{1,2\}$ has as many members as $A$, so these two students are not short of tasks at all. The complete search cannot stop in this way, because (C1) forces it to follow $c$--$2$ as well.

\subsection*{Shortage sets are certificates}
A set $S$ of students with $|N(S)|<|S|$ is called a \emph{shortage set}. If a shortage set exists, then no matching saturates $L$. Indeed, if some matching saturated $L$, each student $s$ of $S$ would have a partner, a task that $s$ accepts and hence a member of $N(S)$, and different students of $S$ would have different partners, because two edges of a matching never share an endpoint. So $N(S)$ would contain $|S|$ different tasks, which is impossible when it has fewer than $|S|$ members.

By Proposition~\ref{ch08:prop:shortage}, the set $A$ reported by a failed search satisfies $|N(A)|=|A|-1<|A|$, so it is a shortage set, and no full assignment exists. A shortage set is an \emph{obstruction}: it blocks every possible way of assigning tasks, not just the choices one search happened to make. It is also easy to check, without trusting or rerunning the search that found it: list the tasks its students accept and count them. Evidence that can be checked directly in this way is called a \emph{certificate}, and a shortage set is also called a \emph{shortage certificate}. A full assignment is a certificate in the other direction: check that every student appears in exactly one pair, that each pair is an edge, and that no task appears twice. So the procedure of Section~\ref{ch08:sec:search} always ends with a certificate, and Chapter~\ref{ch:hall} turns this observation into a theorem.

\begin{principle}{Habit 7: make failure informative}
A failed attempt to build something is not, by itself, a proof that it cannot be built. Ask whether the failure can be turned into a concrete object that violates a necessary condition. Here the condition is that every group of students accepts at least as many tasks as it has members, and the object is a group that accepts too few. Elsewhere, a failed attempt to invert a function may turn up two inputs with the same output, which shows that no inverse exists. When a search, yours or an assistant's, reports that nothing was found, ask whether it produced such an object, and whether it could have missed anything.
\end{principle}
