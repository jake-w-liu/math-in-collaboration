\section{A function includes its input and output sets}\label{ch03:sec:functions}
A \emph{function} $f:A\to B$, read ``$f$ from $A$ to $B$,'' assigns to each input $x\in A$ exactly one output $f(x)\in B$. The set $A$ of allowed inputs is the \emph{domain} of $f$. The set $B$, in which the outputs are required to lie, is the \emph{codomain}, and its elements are called \emph{targets}. The words \emph{map} and \emph{mapping} mean the same as function.

Not every target needs to occur as an output. The outputs that do occur form the \emph{image} of $f$,
\[
f(A)=\{f(x):x\in A\},
\]
the set of all values $f(x)$ obtained as $x$ runs through $A$. For example, let $A=\{p,q,r\}$, where $p,q,r$ are three different objects, let $B=\{1,2,3,4\}$, and define $f(p)=1$ and $f(q)=f(r)=3$. Each input has exactly one output in $B$, so this is a function; two inputs may share an output. The image is $f(A)=\{1,3\}$, and the targets $2$ and $4$ are never reached.

For $f:\RR\to\RR$ given by $f(x)=x^2$, the image is $[0,\infty)$: every output $x^2$ is nonnegative, and every $t\ge0$ is an output, because $f(\sqrt t)=t$ (Section~\ref{ch01:sec:notation}). The codomain, however, is all of $\RR$. A function is specified by three pieces of information, its domain, its codomain, and its rule; the image is something we work out from these.

To name a rule without giving it a letter, we write $x\mapsto x^2$, read ``$x$ maps to $x^2$.'' Two functions $f,g:A\to B$ are \emph{equal} when $f(x)=g(x)$ for every $x\in A$. Functions with different domains or codomains are different, even with the same rule: $x\mapsto x^2$ from $\RR$ to $\RR$ differs from the same rule from $\RR$ to $[0,\infty)$: every target of the second is an output, but the negative targets of the first are never reached. Section~\ref{ch03:sec:injsurj} gives this difference a name.

\pauseq{Does the rule ``send $x$ to a number $y$ with $y^2=x$'' define a function from $\RR$ to $\RR$?}{No, for two reasons. The input $-1$ has no output, since no real number has a negative square, and the input $4$ has two candidate outputs, $2$ and $-2$. A function must give \emph{exactly one} output for \emph{every} input. The rule $t\mapsto\sqrt t$ from $[0,\infty)$ to $\RR$ repairs both problems: it shrinks the domain to the numbers that have a square root, and it always picks the nonnegative root.}

The \emph{identity map} $\id_A:A\to A$ sends each element to itself: $\id_A(x)=x$ for every $x\in A$. If $f:A\to B$ and $g:B\to C$, their \emph{composition} $g\circ f:A\to C$ applies $f$ first and $g$ second:
\[
(g\circ f)(x)=g(f(x)).
\]
This makes sense because every output of $f$ lies in $B$, the set of allowed inputs of $g$. Watch the order: in $g\circ f$, the function written on the right acts first, so read $g\circ f$ as ``$g$ after $f$.''

\subsection*{Composing two concrete maps}
Let $f,g:\RR\to\RR$ be given by $f(x)=x+1$ and $g(y)=2y$. Then $(g\circ f)(3)=g(4)=8$, while $(f\circ g)(3)=f(6)=7$, so $g\circ f$ and $f\circ g$ are different functions. In general,
\[
(g\circ f)(x)=g(x+1)=2(x+1)=2x+2\qquad\text{and}\qquad(f\circ g)(x)=f(2x)=2x+1,
\]
the two expressions compared in Section~\ref{ch01:sec:letters}.

When the codomain of $f$ is not the domain of $g$, the composition can fail to make sense. Let $f:\RR\to\RR$ be $f(x)=x-1$, and let $g:[0,\infty)\to\RR$ be $g(t)=\sqrt t$. Then $g(f(5))=g(4)=2$, but $g(f(0))$ makes no sense, because $f(0)=-1$ is not an allowed input of $g$; so $g\circ f$ is not defined. Using the same rule $x\mapsto x-1$ as a function from $[1,\infty)$ to $[0,\infty)$ fixes this: the composition $x\mapsto\sqrt{x-1}$ is defined on $[1,\infty)$.

\subsection*{Undoing a function}
A function $f:A\to B$ is \emph{reversible}, or \emph{invertible}, if some function $h:B\to A$ undoes it from both sides:
\[
h(f(a))=a\ \text{ for every }a\in A\qquad\text{and}\qquad f(h(b))=b\ \text{ for every }b\in B.
\]
Such an $h$ is called an \emph{inverse} of $f$. Because two functions are equal when they agree at every input, the two conditions say that $h\circ f=\id_A$ and $f\circ h=\id_B$. For $f:\RR\to\RR$, $f(x)=x+1$, an inverse is $h(y)=y-1$: $h(f(x))=(x+1)-1=x$ and $f(h(y))=(y-1)+1=y$.

Both conditions must hold at \emph{every} input. The square root seems to undo squaring, since $\sqrt{3^2}=3$, but for the square map $f:\RR\to\RR$, $f(x)=x^2$, we get $\sqrt{f(-3)}=3$, not $-3$. In fact this $f$ has no inverse at all: an inverse $h$ would need $h(1)=h(f(1))=1$ and also $h(1)=h(f(-1))=-1$, which is impossible.

A function has at most one inverse. Suppose that $h$ and $k$ are both inverses of $f$, and let $b\in B$. Since $f(k(b))=b$, applying $h$ to both sides gives $h(f(k(b)))=h(b)$. Since $h(f(a))=a$ for every $a\in A$, taking $a=k(b)$ gives $h(f(k(b)))=k(b)$. Hence $h(b)=k(b)$ for every $b\in B$, so $h=k$. We may therefore speak of \emph{the} inverse of $f$, usually written $f^{-1}$. This symbol does not mean the reciprocal $1/f$: for $f(x)=x+1$, we have $f^{-1}(1)=0$, while $1/f(1)=1/2$.
