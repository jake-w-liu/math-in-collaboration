\section{Injective, surjective, and reversible}\label{ch03:sec:injsurj}
A function $f:A\to B$ is \emph{injective} if different inputs always give different outputs: whenever $x\ne y$, also $f(x)\ne f(y)$. An injective function loses no information, because each output tells us which input produced it. In proofs it is usually easier to use the contrapositive form of this definition (Chapter~\ref{ch:logic}), which says the same thing with equalities in place of inequalities:
\[
\forall x,y\in A,\qquad f(x)=f(y)\Rightarrow x=y.
\]
In words: if two inputs have the same output, they were the same input. So to prove that $f$ is injective, take arbitrary $x,y\in A$, assume $f(x)=f(y)$, and deduce $x=y$.

A function $f:A\to B$ is \emph{surjective} if every target is an output:
\[
\forall b\in B\ \exists a\in A:\qquad f(a)=b.
\]
Equivalently, the image $f(A)$ is the whole codomain $B$. Read as a sequence of choices, as in Chapter~\ref{ch:logic}, the definition says that someone hands us a target $b$, and we respond with an input $a$, which may depend on $b$. An input $a$ with $f(a)=b$ is a \emph{witness} that $b$ is reached, just as $3$ is the witness for the oddness of $7=2\cdot3+1$ in Chapter~\ref{ch:start}. To prove that $f$ is surjective, take an arbitrary $b\in B$ and produce a witness for it.

A function that is both injective and surjective is \emph{bijective}, and is called a \emph{bijection}. Other books often say \emph{one-to-one} for injective and \emph{onto} for surjective. The two properties are separate requirements. Injectivity keeps different inputs apart; surjectivity makes sure that no target is missed. A function can have either property without the other.

Here are two small examples, one of each kind. The map $f:\{p,q\}\to\{1,2,3\}$ with $f(p)=1$ and $f(q)=2$ is injective, because its two inputs have different outputs. It is not surjective, because no input reaches the target $3$. The map $g:\{p,q,r\}\to\{1,2\}$ with $g(p)=1$, $g(q)=1$, and $g(r)=2$ is surjective, because both targets are reached. It is not injective, because $g(p)=g(q)$ although $p\ne q$. If we are told only that the output of $g$ is $1$, we cannot tell whether the input was $p$ or $q$: that information has been lost.

Why does a bijective function have an inverse? Call an input $a$ a \emph{preimage} of a target $b$ when $f(a)=b$; in other words, a preimage of $b$ is a witness that $b$ is reached. To build an inverse $h$, we must decide, for every target $b$, which input $h(b)$ should be. The two properties of a bijection are exactly what make this decision possible and unambiguous.
\begin{itemize}
\item Surjectivity says that every target $b$ has \emph{at least one} preimage, so there is something to choose.
\item Injectivity says that every target has \emph{at most one} preimage: if $f(a_1)=b$ and $f(a_2)=b$, then $f(a_1)=f(a_2)$, and so $a_1=a_2$. So there is no choice to make.
\end{itemize}
We may therefore define $h(b)$ to be \emph{the} unique preimage of $b$. Now check the two conditions for an inverse. By the definition of $h$, the input $h(b)$ is sent to $b$, so $f(h(b))=b$. For the other condition, start with an input $a$ and look at its output $f(a)$. The input $a$ is certainly a preimage of $f(a)$, and that preimage is unique, so $h(f(a))=a$.

For a small example, let $f:\{p,q,r\}\to\{1,2,3\}$ be given by $f(p)=2$, $f(q)=3$, and $f(r)=1$. Every target is reached exactly once, so $f$ is bijective. Reading the arrows backward gives the inverse: $h(1)=r$, $h(2)=p$, and $h(3)=q$. The general argument above is a careful description of this ``read the arrows backward'' recipe, together with the reason why the recipe produces exactly one answer for each target.

The converse also holds: a function with an inverse must be both injective and surjective. Exercise~\ref{ex:3.5} asks you to prove this. Together, the two facts say that a function is reversible exactly when it is bijective.

For finite sets, these properties also compare sizes. If $f:A\to B$ is injective and $A$ and $B$ are finite, the outputs $f(a)$ for $a\in A$ are $|A|$ different members of $B$, so $|A|\le|B|$. If $f$ is a bijection, those $|A|$ different outputs make up all of $B$, so $|A|=|B|$. Thus a bijection between two finite sets shows that they have the same size, without counting either one. Read as a contrapositive, the first fact says that if $|A|>|B|$, then every map from $A$ to $B$ sends two different inputs to the same output. This is the pigeonhole principle, which Chapter~\ref{ch:graphs} states in the language of objects placed in boxes.

The square map $f:\RR\to\RR$, $f(x)=x^2$, is neither injective nor surjective: $f(1)=f(-1)$, and the target $-1$ is never reached. Now keep the rule but change both sets: let $s:[0,\infty)\to[0,\infty)$ be given by $s(x)=x^2$. This new function is a bijection. For injectivity, suppose $s(x)=s(y)=t$. Then $x$ and $y$ are both nonnegative numbers whose square is $t$. By the fact accepted in Section~\ref{ch01:sec:notation}, a nonnegative real number has exactly one nonnegative square root, so $x=y$. For surjectivity, a target $t\ge0$ is reached by the input $\sqrt t$, which is nonnegative. The inverse of $s$ is the square-root function $t\mapsto\sqrt t$ from $[0,\infty)$ to $[0,\infty)$. Shrinking the domain removed the collision between $1$ and $-1$, and shrinking the codomain removed the negative targets that could never be reached.

\par\noindent\begin{minipage}{\linewidth}
\begin{theorem}\label{thm:injcomp}
If $f:A\to B$ and $g:B\to C$ are injective, then $g\circ f$ is injective.
\end{theorem}
\end{minipage}\par

\noindent\textit{Plan.} An equality of final outputs should let us recover an equality at the intermediate stage, and then an equality of inputs.
\begin{proof}
Take any $x,y\in A$ and assume $g(f(x))=g(f(y))$. The elements $f(x)$ and $f(y)$ belong to $B$, so injectivity of $g$ applies to them and gives $f(x)=f(y)$. Injectivity of $f$ then gives $x=y$. This is exactly the implication required for $g\circ f$ to be injective.
\end{proof}

An assistant may summarize this proof as ``cancel $g$, then cancel $f$.'' That shorthand is fine once it is clear that each cancellation is an application of injectivity. Functions cannot be cancelled in general. For $g:\RR\to\RR$ with $g(y)=y^2$ we have $g(1)=g(-1)$, yet $1\ne-1$, so cancelling $g$ here would lead to a false conclusion.

\par\noindent\begin{minipage}{\linewidth}
\begin{proposition}\label{thm:compconverse}
Let $f:A\to B$ and $g:B\to C$. If $g\circ f$ is injective, then $f$ is injective. However, $g$ need not be injective.
\end{proposition}
\end{minipage}\par

\begin{proof}
Let $x,y\in A$ with $f(x)=f(y)$. Applying the same function $g$ to equal objects gives equal results, so $g(f(x))=g(f(y))$. Injectivity of $g\circ f$ then gives $x=y$. Hence $f$ is injective.

For the second assertion, one example is enough. Take $A=\{0,1\}$, $B=\{0,1,2\}$, $C=\{0,1\}$, and define
\[
f(0)=0,\quad f(1)=1,\qquad g(0)=0,\quad g(1)=g(2)=1.
\]
The composition sends $0$ to $0$ and $1$ to $1$, so it is injective. Yet $g$ is not injective, because the different inputs $1$ and $2$ have the same output.
\end{proof}
Look at why the example works. The composition $g\circ f$ only ever applies $g$ to outputs of $f$, that is, to points of the image $f(A)=\{0,1\}$. The collision $g(1)=g(2)$ involves the point $2$, which $f$ never reaches, so the composition cannot detect it. Studying why a counterexample works often shows what the true statement should be. Here it suggests that $g$ must be injective on the image of $f$, though not necessarily anywhere else.

To say this precisely, we need one more term. If $S$ is a subset of the domain of $g$, the \emph{restriction} of $g$ to $S$ is the function from $S$ to $C$ that uses the same rule as $g$ but accepts only inputs from $S$. Whenever $g\circ f$ is injective, the restriction of $g$ to $f(A)$ is injective. To check this, let $b_1,b_2\in f(A)$ with $g(b_1)=g(b_2)$. Because both points lie in the image, there are inputs $x,y\in A$ with $b_1=f(x)$ and $b_2=f(y)$. Then $g(f(x))=g(f(y))$, so injectivity of $g\circ f$ gives $x=y$, and therefore $b_1=f(x)=f(y)=b_2$. In the example, the restriction of $g$ to $\{0,1\}$ sends $0$ to $0$ and $1$ to $1$, which is injective. The function $g$ fails to be injective only because of the unused point $2$.

This diagnosis also suggests an extra hypothesis under which $g$ itself must be injective. If $f$ is surjective, then $f(A)$ is all of $B$, so no input of $g$ goes untested.

\par\noindent\begin{minipage}{\linewidth}
\begin{proposition}\label{ch03:prop:surjrescue}
Let $f:A\to B$ and $g:B\to C$. If $g\circ f$ is injective and $f$ is surjective, then $g$ is injective.
\end{proposition}
\end{minipage}\par

\begin{proof}
Let $b_1,b_2\in B$ satisfy $g(b_1)=g(b_2)$. Surjectivity of $f$ supplies inputs $a_1,a_2\in A$ with $f(a_1)=b_1$ and $f(a_2)=b_2$. Then
\[
(g\circ f)(a_1)=g(b_1)=g(b_2)=(g\circ f)(a_2),
\]
so injectivity of the composition gives $a_1=a_2$. Applying $f$ to both sides gives $b_1=f(a_1)=f(a_2)=b_2$. Hence $g$ is injective.
\end{proof}
Each hypothesis has a visible job. Surjectivity of $f$ turns every input of $g$ into an output of $f$, and injectivity of $g\circ f$ turns an equality of final outputs back into an equality of inputs.
