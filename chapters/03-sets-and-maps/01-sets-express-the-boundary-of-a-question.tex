\section{Sets express the boundary of a question}\label{ch03:sec:sets}
Section~\ref{ch01:sec:pattern} suggested that the first question to ask about any claim is: which objects does it talk about? A \emph{set} records the answer. It is a collection of objects, called its \emph{members} or \emph{elements}, and it is completely determined by which objects belong to it. So listing a member twice changes nothing, $\{1,1,3\}=\{1,3\}$, and neither does the order of the list: $\{3,1\}=\{1,3\}$.

We write $x\in A$, read ``$x$ is in $A$,'' when $x$ is a member of $A$, and $x\notin A$ when it is not; for example, $3\in\{1,3,5\}$ and $2\notin\{1,3,5\}$. The \emph{empty set} $\varnothing$ has no members at all. We write $A\subseteq B$, read ``$A$ is a \emph{subset} of $B$'' or ``$A$ is contained in $B$,'' when every member of $A$ is also a member of $B$. For example, $\{1,3\}\subseteq\{1,2,3\}$, but $\{1,4\}$ is not a subset of $\{1,2,3\}$, because $4$ is missing from the second set. Every set is a subset of itself.

To prove $A\subseteq B$, begin with ``Let $x\in A$,'' where $x$ is \emph{arbitrary}: as in Chapter~\ref{ch:start}, it stands for any member of $A$, so the argument may use only the fact that $x\in A$. Then show that $x\in B$, without assuming it along the way, since deriving it is the whole point. Because $x$ was arbitrary, this covers every member of $A$.

Three operations build new sets from old ones. The \emph{union} $A\cup B$ consists of the objects in at least one of $A$ and $B$; this is the inclusive ``or'' of Section~\ref{ch02:sec:connectives}, so an object in both sets is in the union. The \emph{intersection} $A\cap B$ consists of the objects in both $A$ and $B$. The \emph{difference} $A\setminus B$ consists of the objects in $A$ but not in $B$. For $A=\{1,2,3\}$ and $B=\{3,4\}$,
\[
A\cup B=\{1,2,3,4\},\qquad A\cap B=\{3\},\qquad A\setminus B=\{1,2\}.
\]
Order matters for a difference, since $B\setminus A=\{4\}$, but not for a union or an intersection.

To describe a set by a property instead of a list, we write $\{x\in A:P(x)\}$ for the set of members of $A$ that have the property $P$; read the colon as ``such that.'' For example, $\{n\in\ZZ:n\text{ is even}\}$ is the set of even integers, and $\{x\in\RR:x^2\le4\}$ is the interval $[-2,2]$, because $x^2\le4$ exactly when $-2\le x\le2$ (Section~\ref{sec:magnitude}).

\subsection*{Membership, containment, and equality}
The symbols $\in$ and $\subseteq$ are easy to confuse, but they connect different kinds of objects: $\in$ has an object on its left and a set on its right, while $\subseteq$ has a set on both sides. Thus $1\in\{1,2\}$ says that the number $1$ is a member, and $\{1\}\subseteq\{1,2\}$ says that every member of the set $\{1\}$ is a member. Both are true; in general, $x\in B$ exactly when $\{x\}\subseteq B$, since the only member of $\{x\}$ is $x$. But the symbols cannot be exchanged. The statement $\{1\}\in\{1,2\}$ is false, because neither member of $\{1,2\}$ is the set $\{1\}$, and $1\subseteq\{1,2\}$ has no meaning, because $1$ is not a set.

Two sets are \emph{equal} when they have exactly the same members. So to prove $D=E$, we prove the two containments $D\subseteq E$ and $E\subseteq D$.

The empty set is a subset of every set $E$. A counterexample to $\varnothing\subseteq E$ would be a member of $\varnothing$ that is not in $E$, and since $\varnothing$ has no members, there is none. This is the set version of vacuous truth from Section~\ref{ch02:sec:contrapositive}. Likewise, a proof beginning ``Let $x\in D$'' remains valid when $D$ is empty: it says what happens whenever a member is supplied, and never claims that one exists.

Try a first set equality on small sets: for $A=\{1,2,3\}$, $B=\{2,4\}$, and $C=\{3,4\}$, we get $A\cap(B\cup C)=A\cap\{2,3,4\}=\{2,3\}$, and $(A\cap B)\cup(A\cap C)=\{2\}\cup\{3\}$ is again $\{2,3\}$. The proof explains why the two sides agree for all sets.

\par\noindent\begin{minipage}{\linewidth}
\begin{proposition}\label{ch03:prop:distributive}
For any sets $A,B,C$, we have $A\cap(B\cup C)=(A\cap B)\cup(A\cap C)$.
\end{proposition}
\end{minipage}\par

\begin{proof}
We prove the two containments separately.

First let $x\in A\cap(B\cup C)$. Then $x\in A$ and $x\in B\cup C$, so $x\in B$ or $x\in C$. If $x\in B$, then $x\in A\cap B$; if $x\in C$, then in the same way $x\in A\cap C$. In either case $x\in(A\cap B)\cup(A\cap C)$. Since $x$ was an arbitrary member of $A\cap(B\cup C)$, this proves $A\cap(B\cup C)\subseteq(A\cap B)\cup(A\cap C)$.

Conversely, let $x\in(A\cap B)\cup(A\cap C)$. Then $x\in A\cap B$ or $x\in A\cap C$. In the first case $x\in A$ and $x\in B$; in the second, $x\in A$ and $x\in C$. In both cases $x\in A$, and $x$ lies in $B$ or in $C$, that is, $x\in B\cup C$. Thus $x\in A\cap(B\cup C)$, which proves the reverse containment, and with it the equality.
\end{proof}

\subsection*{Counting members and forming pairs}
A set is \emph{finite} if its members can be written down in a list that ends, and \emph{infinite} otherwise, like $\NN$ and $\ZZ$. For a finite set $S$, the \emph{size} or \emph{cardinality} $|S|$ is the number of its members. For example, $|\{2,4,6\}|=3$ (we count the members, we do not add them up), and $|\varnothing|=0$. Bars around a real number mean its absolute value (Section~\ref{sec:magnitude}); the kind of object inside the bars tells you which meaning is intended.

Two sets $A$ and $B$ are \emph{disjoint} if they have no member in common, that is, if $A\cap B=\varnothing$. For disjoint finite sets, $|A\cup B|=|A|+|B|$, because each member of the union lies in exactly one of the two sets. For overlapping sets the sum counts too much: $|\{1,2\}|+|\{2,3\}|=4$, but $|\{1,2,3\}|=3$, because the common member $2$ is counted twice. In general, $|A|+|B|$ counts every member of $A\cap B$ twice and every other member of $A\cup B$ once, so
\[
|A\cup B|=|A|+|B|-|A\cap B|\qquad\text{for all finite sets }A,B.
\]

When order matters, we use an \emph{ordered pair} $(a,b)$, with first entry $a$ and second entry $b$. Two ordered pairs are equal exactly when their first entries are equal and their second entries are equal. So $(1,3)\ne(3,1)$, although $\{1,3\}=\{3,1\}$. For example, the winner and the runner-up of a race form an ordered pair, because swapping them changes the result.

The \emph{Cartesian product} $A\times B$ is the set of all ordered pairs $(a,b)$ with $a\in A$ and $b\in B$. If $A=\{1,2\}$ and $B=\{p,q\}$, where $p$ and $q$ are two different objects, then
\[
A\times B=\{(1,p),(1,q),(2,p),(2,q)\}.
\]
Each of the $|A|$ choices of first entry combines with each of the $|B|$ choices of second entry, so $|A\times B|=|A|\cdot|B|$ for finite sets. Despite the multiplication sign, $A\times B$ is a set of pairs; only its \emph{size} is a product of numbers. Products describe inputs made of two pieces: adding two real numbers takes a pair $(x,y)$ from $\RR\times\RR$ and returns $x+y$.
