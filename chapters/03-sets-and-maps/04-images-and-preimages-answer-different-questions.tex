\section{Images and preimages answer different questions}
Let $f:A\to B$. We can apply $f$ to a whole set of inputs at once. For $S\subseteq A$, the \emph{image} of $S$ is
\[
f(S)=\{f(x):x\in S\},
\]
the set of outputs produced by inputs from $S$. It answers the question ``where do these inputs go?'' When $S$ is the whole domain $A$, this is the image $f(A)$ from Section~\ref{ch03:sec:functions}. Going the other way, for $T\subseteq B$, the \emph{preimage} of $T$ is
\[
f^{-1}(T)=\{x\in A:f(x)\in T\},
\]
the set of inputs whose outputs land in $T$. It answers the question ``which inputs end up here?''

For the square map $f:\RR\to\RR$, $f(x)=x^2$, here are some images and preimages:
\begin{gather*}
f(\{-1,1,2\})=\{1,4\},\qquad f^{-1}(\{1\})=\{-1,1\},\\
f^{-1}(\{4,9\})=\{-3,-2,2,3\},\qquad f^{-1}(\{-1\})=\varnothing.
\end{gather*}
The last preimage is empty because no real number has square $-1$. Similarly, $f^{-1}([0,4])=[-2,2]$. Indeed, $0\le x^2$ holds for every real $x$, and $x^2\le4$ holds exactly when $-2\le x\le2$, as we saw in Section~\ref{ch03:sec:sets}.

The notation $f^{-1}(T)$ does not require $f$ to have an inverse. The square map has no inverse, as Section~\ref{ch03:sec:functions} showed, yet all of its preimages make sense. When $f$ does have an inverse, the two readings of the symbol agree: the preimage $f^{-1}(T)$ is then the same set as the image of $T$ under the inverse function. So the shared notation never leads to two different answers.

\pauseq{For the square map $f:\RR\to\RR$, compute $f^{-1}(f(\{2\}))$. Do you get back $\{2\}$?}{First $f(\{2\})=\{4\}$. Then $f^{-1}(\{4\})=\{-2,2\}$, which is larger than $\{2\}$. Going forward and then backward returns every input that shares an output with $2$, and $-2$ is such an input. If $f$ is injective, nothing extra comes back: each input $x$ is the only input with output $f(x)$, so $f^{-1}(f(S))=S$ for every $S\subseteq A$.}

Preimages fit well with the set operations of Section~\ref{ch03:sec:sets}. For any $S,T\subseteq B$,
\[
f^{-1}(S\cap T)=f^{-1}(S)\cap f^{-1}(T).
\]
Read the left side as ``the inputs whose outputs land in the intersection.'' We can justify the identity one membership condition at a time. For any $x\in A$,
\begin{align*}
 x\in f^{-1}(S\cap T)
 &\Longleftrightarrow f(x)\in S\cap T &&\text{definition of preimage}\\
 &\Longleftrightarrow f(x)\in S\text{ and }f(x)\in T
 &&\text{definition of intersection}\\
 &\Longleftrightarrow x\in f^{-1}(S)\text{ and }x\in f^{-1}(T)
 &&\text{definition of preimage}\\
 &\Longleftrightarrow x\in f^{-1}(S)\cap f^{-1}(T)
 &&\text{definition of intersection}.
\end{align*}
Each double arrow $\Longleftrightarrow$ means ``if and only if,'' so each step is valid in both directions. Reading the chain downward shows that every member of the left side lies in the right side, and reading it upward shows the reverse containment. Since $x$ was an arbitrary element of $A$, the two sets have exactly the same members. No inverse function was used. Chapter~\ref{ch:lean2} expresses these same membership conditions in the proof assistant Lean. Exercise~\ref{ex:3.4} asks for the corresponding identity for unions, and Exercise~\ref{ex:3.6} asks whether images behave as well as preimages do.

\begin{principle}{Habit 3: identify the information actually used}
When you read or write a proof, ask which facts it actually uses and where it uses them. A statement about every target can be much stronger than a statement about the outputs that are actually reached. In Proposition~\ref{thm:compconverse}, the composition $g\circ f$ only ever tests $g$ at points of the image $f(A)$. A conclusion about $g$ on all of $B$ therefore asks for more than the argument can give, and in this case more than is true. The same question can also show that a result reaches further than it first seems to. The proof of Proposition~\ref{ch03:prop:distributive} used only the pattern of membership, never what the elements were, which is why it holds for sets of any objects. Before you propose a generalization, or accept one from an assistant, locate the part of each object that the proof actually visits.
\end{principle}
