\section{Three ways to use an equation}\label{ch15:sec:equality}
The first way to use an equation is to apply the same function to both sides: if $x=y$, then $f(x)=f(y)$. In Lean, if \code{h} proves \code{x = y}, then \code{congrArg f h} proves \code{f x = f y}; the name is short for ``congruence in the argument,'' the \emph{argument} of a function being its input. This works for every function. Injectivity goes the other way, from $f(x)=f(y)$ to $x=y$, and holds only for some functions: squaring on $\RR$ sends $1$ and $-1$ to the same output (Section~\ref{ch03:sec:injsurj}).

The second way is to substitute. If \code{h : a = b}, the tactic \code{rw [h]} rewrites the goal, replacing every occurrence of the left side \code{a} by the right side \code{b}. Afterwards \code{rw} tries \code{rfl} by itself, so a goal that has become an equation with identical sides is closed at once:
\par\noindent\begin{minipage}{\linewidth}
\begin{lstlisting}
theorem add_one_of_eq (a b : Nat) (h : a = b) :
    a + 1 = b + 1 := by
  rw [h]
\end{lstlisting}
\end{minipage}\par
The rewrite turns the goal \code{a + 1 = b + 1} into \code{b + 1 = b + 1}, which \code{rw} then closes; on paper, ``since $a=b$, substitute $b$ for $a$.'' The brackets may also hold several equations, separated by commas, which \code{rw} uses one after another.

The third way, for a chain of equalities, is Lean's \code{calc} block~\cite{leanquant}. Each line states one link of the chain, with its justification after \code{:=}, and Lean combines the links by transitivity: if $a=b$ and $b=c$, then $a=c$. Here is the first half of Exercise~\ref{ex:3.5}: a function with a left inverse is injective.
\par\noindent\begin{minipage}{\linewidth}
\begin{lstlisting}
theorem left_inverse_inj {A B : Type}
    (f : A -> B) (g : B -> A)
    (h : forall x, g (f x) = x) : Inj f := by
  intro x y hxy
  calc
    x = g (f x) := (h x).symm
    _ = g (f y) := congrArg g hxy
    _ = y := h y
\end{lstlisting}
\end{minipage}\par

The hypothesis \code{h} says that $g(f(x))=x$ for every $x$; Lean infers that $x$ ranges over \code{A}, because \code{f} is applied to it. Since functions are equal when they agree at every input (Section~\ref{ch03:sec:functions}), this is the condition $g\circ f=\id_A$ of Exercise~\ref{ex:3.5}, stated one input at a time. (The exercise calls the left inverse $h$; here \code{h} names the hypothesis.) As in Section~\ref{ch15:sec:injcomp}, \code{intro x y hxy} introduces \code{x}, \code{y} and \code{hxy : f x = f y}, leaving the goal \code{x = y}. The \code{calc} block is the Lean form of the chain
\[
x=g(f(x))=g(f(y))=y,
\]
where the underscore at the start of a line stands for the right side of the line before.
\begin{itemize}
\item The first link, \code{x = g (f x)}, comes from \code{h x}, which proves \code{g (f x) = x}, with the sides in the other order. The suffix \code{.symm} (for \emph{symmetry}) reverses an equation: if \code{e} proves \code{a = b}, then \code{e.symm} proves \code{b = a}. The parentheses in \code{(h x).symm} are needed: Lean would read \code{h x.symm} as \code{h} applied to \code{x.symm} and report an error.
\item The second link is \code{congrArg g hxy}: apply $g$ to both sides of $f(x)=f(y)$.
\item The third link, \code{g (f y) = y}, is \code{h y}.
\end{itemize}
