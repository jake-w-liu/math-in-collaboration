\section{A quadratic example, worked by hand}\label{ch12:sec:example}
In the example $T(x)=(x+1)/2$ we knew the fixed point from the start. Here is an example in which the theorem does real work. Let
\[
T(x)=\frac{x^2+1}{3}\qquad\text{on }X=[0,1],
\]
with the usual distance $|x-y|$. Before using the theorem, we check each hypothesis.
\begin{itemize}
\item \emph{The space.} The interval $[0,1]$ is nonempty, and Section~\ref{ch11:sec:complete} proved that it is complete.
\item \emph{The self-map condition.} If $0\le x\le1$, then $0\le x^2\le1$, so $1\le x^2+1\le2$ and $1/3\le T(x)\le2/3$. In particular $T(x)\in[0,1]$, so $T$ maps $[0,1]$ into itself.
\item \emph{The contraction inequality.} For $x,y\in[0,1]$, factor the difference of two squares, $x^2-y^2=(x-y)(x+y)$, and use $|ab|=|a|\,|b|$:
\[
|T(x)-T(y)|=\frac{|x^2-y^2|}{3}=\frac{|x-y|\,|x+y|}{3}\le\frac23|x-y|.
\]
The last step uses $0\le x+y\le2$, which holds because both $x$ and $y$ lie between $0$ and $1$. So $q=2/3$ is a contraction factor.
\end{itemize}
By Theorem~\ref{thm:banach}, $T$ has exactly one fixed point $x_*$ in $[0,1]$, and the iterates from every starting point in $[0,1]$ converge to it. We now find out how close a few iterates are, without solving any equation.

\subsection*{Iterates and a certificate}
Start from $x_0=0$. We compute with exact fractions; in particular, when we square an iterate we square the fraction itself, not a rounded decimal.
\begin{align*}
x_1&=\frac{0^2+1}{3}=\frac13,\\
x_2&=\frac{(1/3)^2+1}{3}=\frac{1/9+9/9}{3}=\frac{10/9}{3}=\frac{10}{27},\\
x_3&=\frac{(10/27)^2+1}{3}=\frac{100/729+729/729}{3}=\frac{829/729}{3}=\frac{829}{2187}.
\end{align*}
Take $z=x_2$. Then $Tz=x_3$, so the residual of $z$ is $|x_2-x_3|$. To subtract, write $x_2$ over the denominator $2187=27\cdot81$, namely $x_2=810/2187$. Then
\[
d(z,Tz)=\left|\frac{810}{2187}-\frac{829}{2187}\right|=\frac{19}{2187}.
\]
Since $1/(1-q)=1/(1-2/3)=3$, the residual estimate \eqref{eq:residual} gives the certificate
\[
d(x_2,x_*)\le3\cdot\frac{19}{2187}=\frac{19}{729}\approx0.026.
\]
So $x_2=10/27\approx0.370$ is guaranteed to lie within $0.027$ of the fixed point, although we do not yet know where the fixed point is.

The other two estimates of Section~\ref{ch12:sec:estimates} give weaker bounds for the same point. The a priori estimate, with $D=d(x_1,x_0)=1/3$ and $n=2$, gives
\[
d(x_2,x_*)\le\frac{(2/3)^2}{1-2/3}\cdot\frac13=\frac49\approx0.44,
\]
because it uses only the first step. The a posteriori estimate uses the step from $x_1=9/27$ to $x_2=10/27$ and gives $d(x_2,x_*)\le\frac{2/3}{1/3}\cdot\frac1{27}=\frac2{27}\approx0.074$. The residual estimate is the sharpest of the three here, because it uses the extra information contained in $x_3$.

\subsection*{Checking against the exact solution}
In this example we can also find $x_*$ exactly, which lets us see how good the certificate is. The fixed-point equation $(x^2+1)/3=x$ becomes $x^2+1=3x$, that is, $x^2-3x+1=0$. Multiply by $4$ and add $5$ to both sides to complete the square:
\[
4x^2-12x+9=5,\qquad\text{that is,}\qquad(2x-3)^2=5.
\]
If $a^2=5$, then $(a-\sqrt5)(a+\sqrt5)=a^2-5=0$, so $a=\sqrt5$ or $a=-\sqrt5$. Hence $2x-3=\pm\sqrt5$, and $x=(3+\sqrt5)/2$ or $x=(3-\sqrt5)/2$. Since $4<5<9$, we have $2<\sqrt5<3$. So $(3+\sqrt5)/2$ is larger than $5/2$ and lies outside $[0,1]$, while $3-\sqrt5$ lies between $0$ and $1$, so $(3-\sqrt5)/2$ lies between $0$ and $1/2$. The fixed point in $[0,1]$ is therefore
\[
x_*=\frac{3-\sqrt5}{2}\approx0.382.
\]
The true error of $x_2$ is $x_*-10/27\approx0.0116$, comfortably below the certificate $19/729\approx0.026$, just as the theorem promised.

On the whole real line, the same formula has two fixed points, $(3\pm\sqrt5)/2$. This does not contradict uniqueness, because the theorem was applied on $[0,1]$ only. On $\RR$ the map is not a contraction: two different fixed points $a$ and $b$ would satisfy $d(Ta,Tb)=d(a,b)$, which the contraction inequality forbids. So the choice of the space $X$ matters: the uniqueness in Theorem~\ref{thm:banach} is a statement about fixed points that lie in $X$.
