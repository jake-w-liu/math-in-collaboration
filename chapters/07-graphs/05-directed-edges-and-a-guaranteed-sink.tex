\section{Directed edges and a guaranteed sink}\label{ch07:sec:sink}
Some connections have a direction: a one-way street, a link from one web page to another, a game that one player won against another. We record such a connection as an arrow.

\par\noindent\begin{minipage}{\linewidth}
\begin{definition}[Directed and oriented graphs]\label{ch07:def:directed}
A \emph{directed graph} consists of a set $V$ of vertices and a set of \emph{directed edges}. Each directed edge is an ordered pair $(u,v)$ of two different vertices; we write it $u\to v$ and draw it as an arrow from $u$ to $v$. An \emph{oriented graph} is a directed graph in which no two vertices are joined in both directions: $u\to v$ and $v\to u$ never both occur.
\end{definition}
\end{minipage}\par

Because the entries of an ordered pair come in a definite order (Section~\ref{ch03:sec:sets}), $u\to v$ and $v\to u$ are different directed edges. As with graphs, there are no loops: a directed edge always joins two different vertices. Some pairs of vertices may have no edge in either direction. In this section the set of vertices is allowed to be infinite, and we say ``finite'' explicitly whenever a result needs it.

If $u\to w$, we call $w$ an \emph{out-neighbor} of $u$. The \emph{outdegree} of $u$ is the number of its out-neighbors, that is, the number of arrows leaving $u$. A \emph{sink} is a vertex with outdegree $0$: no arrow leaves it.

Walks and paths now have to follow the arrows. A \emph{directed walk} from $v_0$ to $v_k$ is a sequence of vertices $v_0,v_1,\ldots,v_k$ with $v_{i-1}\to v_i$ for every $i=1,\ldots,k$; its length is $k$. A \emph{directed path} is a directed walk with no repeated vertex. A \emph{directed cycle} is a directed walk $v_0,v_1,\ldots,v_k$ with at least one step, $k\ge1$, that returns to its start, $v_k=v_0$, and has no other repetition: the vertices $v_0,v_1,\ldots,v_{k-1}$ are all different. A directed graph is \emph{acyclic} when it has no directed cycle. Being acyclic does not mean having no edges; it means that no route along the arrows ever returns to where it started.

In an oriented graph, every directed cycle passes through at least three vertices. A cycle with one step would be a loop $v_0\to v_0$, and a cycle with two steps would need both $v_0\to v_1$ and $v_1\to v_0$. Both are forbidden. Here are two oriented graphs, each with vertices $a$, $b$, $c$:

\end{tikzpicture}
\end{center}
On the left is the \emph{chain} $a\to b\to c$. It is acyclic: every arrow leads further along the chain, so no directed walk can come back. Its vertex $c$ is a sink, while $a$ and $b$ are not. On the right is the directed cycle $a\to b\to c\to a$.

Does every directed graph have a sink? Not without some hypotheses. A graph with no vertices has no sink, simply because it has no vertices at all. An infinite graph can fail too. Take the natural numbers as vertices, with an edge $n\to n+1$ for every $n$. Every vertex points to the next one, so there is no sink. Yet this graph is acyclic, because the numbers strictly increase along any directed walk, so a walk can never return to its starting number. Exercise~\ref{ex:7.3} asks what can happen when the graph is finite but not acyclic. The next theorem shows that a sink must exist once the graph is nonempty, finite, and acyclic.

\par\noindent\begin{minipage}{\linewidth}
\begin{theorem}\label{thm:sink}
Every nonempty finite acyclic oriented graph has a sink.
\end{theorem}
\end{minipage}\par

Here \emph{nonempty} means that there is at least one vertex. The theorem promises \emph{one} vertex with no outgoing edge; it does not say that every vertex has this property. In the chain, only $c$ is a sink. In a graph with a single vertex and no edges, that one vertex is a sink.

\noindent\textit{Plan.} Take a directed path that is as long as possible, and look at its last vertex. An arrow leaving that vertex would either reach a new vertex, which would give a longer path, or return to the path, which would close a directed cycle.
\begin{proof}
A directed path never repeats a vertex, so it lists at most $|V|$ vertices. The finite set $V$ allows only finitely many lists of at most $|V|$ different vertices, so the graph has only finitely many directed paths. It has at least one: since the graph is nonempty, we can pick a vertex, and a single vertex is a directed path of length $0$. The lengths of the directed paths therefore form a nonempty finite set of natural numbers, which has a largest member. Choose a directed path of this greatest length, and write it $v_0\to v_1\to\cdots\to v_k$.

Suppose, for contradiction, that its last vertex $v_k$ has an out-neighbor $w$.
\begin{itemize}
\item If $w$ is not on the path, then $v_0\to v_1\to\cdots\to v_k\to w$ is a directed walk with no repeated vertex, that is, a directed path. Its length is $k+1$, which contradicts the choice of a path of greatest length.
\item If $w$ is on the path, say $w=v_j$, then $j\ne k$, because $v_k\to v_k$ would be a loop. So $j<k$. Then $v_j\to v_{j+1}\to\cdots\to v_k\to v_j$ is a directed walk with $k-j+1$ steps that returns to its start, and its vertices $v_j,\ldots,v_k$ before the return are all different. It is a directed cycle, which contradicts acyclicity.
\end{itemize}
Both cases are impossible. Hence $v_k$ has no out-neighbor, so it is a sink.
\end{proof}

Each hypothesis has a visible job in this proof. Nonemptiness supplies at least one path to choose from. Finiteness guarantees a path of greatest length; in the infinite graph on the natural numbers, every path can be extended by one more step. Acyclicity rules out an arrow from the last vertex back into the path.

The proof also suggests a way to find a sink. Start at any vertex and keep following arrows, choosing any outgoing arrow at each step, for as long as possible. In an acyclic graph the walk never returns to a vertex it has already visited: the first time it did so, the stretch of the walk between the two visits would be a directed cycle. So in a finite graph the walk reaches a new vertex at every step, and it must stop after at most $|V|-1$ steps. It can stop only at a vertex with no outgoing arrow, that is, at a sink.
